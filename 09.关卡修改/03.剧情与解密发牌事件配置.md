# 03. 剧情与解密发牌事件配置

PVZH 丰富的新手教学、单人战役剧情对话以及每日解密挑战（Puzzle Party）的固定发牌/强制出牌逻辑，全靠关卡 JSON 中的 **`GameEvents`** 列表驱动。

本篇详细解析 4 大常用游戏事件节点。

---

## 一、 游戏事件 (`GameEvents`) 结构

在关卡 JSON 中，`GameEvents` 是一个按触发顺序排列的事件列表：

```json
"GameEvents": [
  {
    "$type": "PvZCards.Engine.Config.MessageEventConfig, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
    "MessageLocKey": "tutorial_dialog_01",
    "Speaker": 0
  }
]
```

---

## 二、 4 大常用游戏事件节点详解

### 1. 剧情对话事件 (`MessageEventConfig`)

在战斗开始或特定回合弹出人物对话框（如疯狂戴夫、僵尸博士或英雄台词）。

```json
{
  "$type": "PvZCards.Engine.Config.MessageEventConfig, EngineLib...",
  "MessageLocKey": "dialog_level_solar_flare_01",
  "Speaker": 0
}
```
- **`MessageLocKey`**：剧情字幕的 Key，需要在本地化文件 [cn.csv](../资源/cn.csv) 中配置对应的中文文本。
- **`Speaker`**：说话者角色头像（`0` 疯狂戴夫 / `1` 僵尸博士 / 特殊英雄 ID）。

---

### 2. 解密发牌事件 (`AddCardToTopOfDeckConfig`)

在解密挑战中，常用于在回合开始前将指定的卡牌精准塞入牌库顶部，确保玩家下一抽必得该卡牌。

```json
{
  "$type": "PvZCards.Engine.Config.AddCardToTopOfDeckConfig, EngineLib...",
  "CardGuid": 900000001,
  "TargetPlayer": 0
}
```
- **`CardGuid`**：目标卡牌的 GUID。
- **`PlayerFaction` / `TargetPlayer`**：接收卡牌的目标阵营（**`0` 代表植物阵营 Plants，`1` 代表僵尸阵营 Zombies**）。

---

### 3. 强制抽卡事件 (`MoveCardToTopOfDeckConfig`)

将卡牌从牌库直接抓取放入手牌，常用于保障解密关卡中玩家获得完成解密所需的关键 Key 牌。

---

### 4. 脚本化强制出牌事件 (`ScriptedTurnEventConfig`)

在新手教程或解密挑战中，强制 AI 或玩家在特定回合必须将某张卡牌打出到指定线路上。

```json
{
  "$type": "PvZCards.Engine.Config.ScriptedTurnEventConfig, EngineLib...",
  "CardGuid": 900000001,
  "LaneIndex": 1,
  "TurnIndex": 1
}
```
- **`LaneIndex`**：强制打出的路线索引（`0`~`4` 代表 5 条路线）。
- **`TurnIndex`**：触发该强制出牌行为的目标回合数。

---

## 编排建议

> [!TIP]
> 剧情对话事件与发牌事件支持按顺序链式串联。在制作自定义解密关卡时，建议在 [PVZH-Level-Editor](https://github.com/Show-o4210/PVZH-Level-Editor) 的 **「游戏事件」** 选项卡中进行可视化拖拽排序与编辑，避免手写 C# 类型字符串错拼。
