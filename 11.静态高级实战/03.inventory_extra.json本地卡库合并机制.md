# 03. inventory_extra.json 本地卡库合并机制

在经过 v3c 补丁修补的 `libil2cpp.so` 运行期驱动下，开发者无需重新编译二进制 SO，即可通过修改外部文本配置文件 **`inventory_extra.json`** 自由开断或追加任意自定义卡牌的拥有数量。

本篇详细讲解该配置文件的数据结构、与 `card_data` 的双轨映射关系以及本地持久化数据流。

---

## 一、 文件存放物理路径

在设备或模拟器中，`inventory_extra.json` 放置在客户端只读缓存的 Mod 专用目录下：

```text
/storage/emulated/0/Android/data/com.ea.gp.pvzheroes/files/cache/mod/inventory_extra.json
```

---

## 二、 `inventory_extra.json` 规范数据格式

该 JSON 文件结构极其精简，采用了 `GUID: 数量` 的 KV 字典键值对表示法：

```json
{
  "version": 1,
  "cards": {
    "900000001": 4,
    "900000002": 4,
    "900000101": 4
  }
}
```

### 属性节点含义说明：

| 节点 Key | 数据类型 | 说明与限制 |
| :--- | :---: | :--- |
| **`version`** | `int` | 配置规范版本号，固定填 `1`。 |
| **`cards`** | `object` | 拥有权卡牌映射表。Key 为卡牌的数字 **GUID**（字符串），Value 为拥有数量（建议填 `4`）。 |

---

## 三、 双轨协作架构：`card_data_*` 结合 `inventory_extra.json`

制作一个完整的离线自定义卡牌 Mod，需要以下两份文件精密配合：

```text
                   ┌────────────────────────────────────────┐
                   │  card_data_* (放置于 files/cards/)     │
                   │  定义 GUID 900000001 的费用、攻防与技能 │
                   └───────────────────┬────────────────────┘
                                       │
                                       ├────── GUID 匹配 ──────┐
                                       │                       │
                   ┌───────────────────┴────────────────────┐  │
                   │  inventory_extra.json (放置于 mod/)    │  │
                   │  声明 "900000001": 4 (持有量为4张)      │  │
                   └───────────────────┬────────────────────┘  │
                                       │                       │
                                       ▼                       ▼
                   ┌────────────────────────────────────────┐
                   │  静态补丁 so 在 SetLocalPlayerInventory  │
                   │  合并生成内存 PlayerInventory.Cards 字典  │
                   └───────────────────┬────────────────────┘
                                       │
                                       ▼
                   ┌────────────────────────────────────────┐
                   │  卡册完美解锁！可无限制拖入 40 张卡组编组 │
                   └────────────────────────────────────────┘
```

1. **如果在 `card_data` 中加了新卡，但没在 `inventory_extra.json` 中写 GUID**：
   - 卡册能看到这张卡，但显示为**未拥有灰色状态**，无法组进卡组。
2. **如果在 `inventory_extra.json` 中写了 GUID，但 `card_data` 中没有该定义**：
   - SO 合并卡库时会因为无法在引擎数据字典中找到对应的对象而自动忽略，不会导致游戏崩溃。

---

## 四、 本地持久化与防覆盖提醒

1. **本地存档路径**：
   在单机离线状态下，合并后的卡组编组会进一步保存在玩家本地存档目录（`/data/data/com.ea.gp.pvzheroes/files/PlayerData/<personaId>/PlayerDecks`）中。
2. **网络同步**：
   当连接 EA 官方服务器时，服务器从云端拉取的账号 Inventory 覆盖本地数据。因此，添加自定义卡牌时建议在**断网离线模式或单机对战**中使用。
