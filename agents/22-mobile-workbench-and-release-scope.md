# 22 · 手机工作台、组件编辑与发布范围

截至2026-10-29，后续Android产品的交付候选为R48 RC2。先读[第24章](../24.启动器工作台与手机编辑/README.md)，按需进入手动编辑、AI模式、资源／媒体／文字包和界面命名；基础字段与原版来源仍回到第02、09、22、23章核对。

- 手动卡牌编辑有基础、词条、积木、保存四个主操作；统一返回、撤销／重做、长按操作及同列表拖动。玩家原始JSON、工程导入导出和紧凑模式已移除；整个Mod ZIP的导入导出保留。
- 组件块将已有原生子树封装成可变参数的配方，不是新增原生类型。内部默认展开；过大树保留渲染预算和逐层聚焦。未知数据保留，不能因UI看不到就删除。
- 快速模式直接制作后程序校验，专家模式增加独立理解／模型审查；两者工具权限相同。关卡共用原流程。手工组件工具尚未全部接入AI，不能承诺任意复杂技能、一次成功或已证实降耗。
- 当前官方资源全量检查由用户手动触发；普通进入复用准备记录及必要固定元数据检查。R32自动同步、R43后台自动确认是各自历史，不能当成R48现行策略。
- 出牌媒体需要Mod明确登记，图标出现和用户点击分别发生。网页跳转、本地视频和在线视频的验收不同；媒体创作尚未接入AI工具。
- 文言文包首次内置导入置顶且默认关闭，后续排序／开关由用户掌握。它完整替换中文资源，与玩法Mod叠加可能让说明和实际技能不一致，不自动逐条合并。
- 当前资料记录的编译／产物、模型回读、Android UI及原内核代表场景各有范围。R48 UI回归不覆盖全部正式对局、所有手机或真实AI流程；快速／专家模式的成本和成功率需要独立测试。

本库提供文档与筛选摘要，完整Android工程、游戏原件、安装包、调试接口、签名及账户备份独立保存。没有本机工程也应能阅读文档；不要把本机绝对路径当成克隆后的必需依赖。
