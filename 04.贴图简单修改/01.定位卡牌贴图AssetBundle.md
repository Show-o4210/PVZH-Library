# 01. 定位卡牌贴图 AssetBundle

在 PVZH 中，单位与卡牌的贴图资源数量庞大且文件名均经过了哈希处理（如 `1f826228d36c6f0478c72b56f17541d2_1`）。想要修改某张卡牌的贴图，首先需要快速定位其对应的资源包文件。

本篇讲解两种最通用的贴图定位方法。

---

## 方法一：使用 `index_new.json` 索引查找（精确定位）

在项目资源目录下，提供了一份全卡牌资源索引表 [index_new.json](../资源/index_new.json)。

### 查找步骤：
1. 使用编辑器（如 VS Code、Sublime Text）打开 [index_new.json](../资源/index_new.json)。
2. 按 `Ctrl+F` 搜索你要修改的卡牌中文名（`NAME_CN`）或英文名（`NAME_EN`）。
3. **查阅条目信息**：
   例如搜索 `康加僵尸`（`Conga Zombie`），找到如下索引对象：

```json
{
  "GUID": "3",
  "UUID": "51457c7b-f561-4250-9e29-a0e4bbd34cce",
  "NAME_CN": "康加僵尸",
  "NAME_EN": "Conga Zombie",
  "TEXTURE_NAME": "1f826228d36c6f0478c72b56f17541d2_1",
  "BUNDLE": "autotagged/1f826228d36c6f0478c72b56f17541d2",
  "CACHE_PATH": "com.ea.gp.pvzheroes/files/cache/bundles/files/autotagged/1f826228d36c6f0478c72b56f17541d2_1"
}
```

4. **锁定目标文件**：
   根据 `TEXTURE_NAME` 或 `CACHE_PATH`，直接在手机或解包目录的 `files/autotagged/` 路径下找到文件名叫 **`1f826228d36c6f0478c72b56f17541d2_1`** 的贴图包。

---

## 方法二：使用 AssetStudio 预览查找（无需索引）

如果你手中没有索引表，或者想要查找某些未录入索引的衍生单位/特效贴图，可以使用 AssetStudio 进行图形化批量搜索。

### 操作步骤：
1. 打开 **AssetStudio**。
2. 点击菜单栏 **`File` -> `Load folder`**，选择本地存放 `files/autotagged/` 贴图包的完整文件夹。
3. 载入完成后，切换到 **`Asset List`** 标签页。
4. 在左侧 `Filter Options` -> `Filter Type` 中仅勾选 **`Texture2D`**。
5. 在列表中点击任意贴图，右侧预览区域会实时显示图片内容。
6. 当在预览框中找到目标卡牌贴图时，看列表中的 **`Source File`** 列，该列显示的字符串就是对应的贴图 AssetBundle 文件名。

---

## 总结比较

| 方法 | 优点 | 缺点 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **方法一：index_new.json 索引** | 毫秒级极速查找，准确率 100% | 仅覆盖标准卡牌 | 已知卡牌名称，快速锁定文件。 |
| **方法二：AssetStudio 预览** | 直观可视化，支持查找衍生特效与部件 | 批量加载耗时，需逐个滚动预览 | 未知文件名或查找自定义衍生素材。 |
