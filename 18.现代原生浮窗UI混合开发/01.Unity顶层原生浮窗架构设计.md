# 01. Unity 顶层原生浮窗架构设计

在 Android 游戏上叠加悬浮窗时，开发者通常首先想到的是申请系统的“悬浮窗权限（`SYSTEM_ALERT_WINDOW`）”。但这会强迫玩家跳出游戏、进入复杂的系统设置页手动授权，极大地破坏了开箱即用的体验。

本篇讲解如何巧妙利用 **`TYPE_APPLICATION` 应用内子窗口机制**，实现**零多余系统权限申请、直接附着于 Unity 游戏主窗口之上的原生悬浮球**，并彻底解决触控事件向下穿透误触游戏的难题。

---

## 一、 窗口层级选型：`SYSTEM_ALERT_WINDOW` vs `TYPE_APPLICATION`

```text
【模式 A：全局系统悬浮窗 (TYPE_APPLICATION_OVERLAY)】
  - 权限要求：必须申请 android.permission.SYSTEM_ALERT_WINDOW
  - 玩家体验：必须跳转系统“在其他应用上层显示”设置页，极易被玩家拒绝
  - 生命周期：独立于游戏，游戏退到后台后悬浮球依然死皮赖脸挂在手机桌面上

【模式 B：应用内附着子窗口 (TYPE_APPLICATION) —— ⭐ 推荐】
  - 权限要求：零额外权限！在 AndroidManifest 中无需增加任何权限声明
  - 玩家体验：随游戏启动自动出现，无感、免配置、即装即用
  - 生命周期：与游戏 UnityPlayerActivity 严格绑定，游戏退后台或切关卡自动隐藏
```

通过获取当前 `UnityPlayerActivity` 的顶级窗口凭证（`Window Token`），我们可以直接在游戏画面上层开辟独立的渲染容器。

## 二、 实战：构建边缘吸附悬浮球（Frida Java 实现）

以下是一套完整的在 Unity 画面边缘创建半透明拖拽悬浮球的 JavaScript/Java 核心实现：

```javascript
// floating_ball_factory.js

function createFloatingButton(activity, onClickCallback) {
    Java.perform(() => {
        const WindowManager = Java.use("android.view.WindowManager");
        const LayoutParams = Java.use("android.view.WindowManager$LayoutParams");
        const Gravity = Java.use("android.view.Gravity");
        const PixelFormat = Java.use("android.graphics.PixelFormat");
        const Button = Java.use("android.widget.Button");
        const View = Java.use("android.view.View");
        const GradientDrawable = Java.use("android.graphics.drawable.GradientDrawable");
        const Color = Java.use("android.graphics.Color");

        const windowManager = Java.cast(activity.getSystemService("window"), WindowManager);

        // 1. 创建布局参数 (零权限的核心: TYPE_APPLICATION)
        const params = LayoutParams.$new(
            LayoutParams.WRAP_CONTENT.value,
            LayoutParams.WRAP_CONTENT.value,
            LayoutParams.TYPE_APPLICATION.value, // 附着于当前 Activity
            LayoutParams.FLAG_NOT_FOCUSABLE.value, // 不抢占输入法焦点，允许游戏响应其他区域
            PixelFormat.TRANSLUCENT.value
        );

        params.gravity.value = Gravity.TOP.value | Gravity.START.value;
        params.x.value = 20;  // 初始水平距离
        params.y.value = 300; // 初始垂直高度

        // 2. 动态创建现代化圆形按钮 (纯代码构建，无需 XML 依赖)
        const btn = Button.$new(activity);
        btn.setText("+");
        btn.setTextSize(22);
        btn.setTextColor(Color.WHITE.value);

        // 创建圆角背景
        const bg = GradientDrawable.$new();
        bg.setShape(GradientDrawable.OVAL.value);
        bg.setColor(Color.parseColor("#CC1976D2")); // 现代半透明 Material 蓝
        btn.setBackground(bg);
        btn.setAlpha(0.6); // 平时半透明，不遮挡游戏对局视野

        // 3. 实现触控拖拽与防误触判断
        let initialX = 0, initialY = 0;
        let initialTouchX = 0, initialTouchY = 0;
        let isMoving = false;

        const TouchListener = Java.registerClass({
            name: "com.pvzh.mod.FloatingTouchListener",
            implements: [View.OnTouchListener],
            methods: {
                onTouch: function (view, event) {
                    const action = event.getAction();
                    const rawX = event.getRawX();
                    const rawY = event.getRawY();

                    if (action === 0) { // ACTION_DOWN
                        initialX = params.x.value;
                        initialY = params.y.value;
                        initialTouchX = rawX;
                        initialTouchY = rawY;
                        isMoving = false;
                        btn.setAlpha(1.0); // 触摸时恢复完全不透明
                        return true;
                    } else if (action === 2) { // ACTION_MOVE
                        const deltaX = rawX - initialTouchX;
                        const deltaY = rawY - initialTouchY;
                        if (Math.abs(deltaX) > 10 || Math.abs(deltaY) > 10) {
                            isMoving = true;
                            params.x.value = initialX + deltaX;
                            params.y.value = initialY + deltaY;
                            windowManager.updateViewLayout(btn, params);
                        }
                        return true;
                    } else if (action === 1) { // ACTION_UP
                        btn.setAlpha(0.6);
                        if (!isMoving) {
                            // 判定为纯点击，触发回调展开主菜单
                            onClickCallback();
                        }
                        return true;
                    }
                    return false;
                }
            }
        });

        btn.setOnTouchListener(TouchListener.$new());

        // 4. 添加至窗口
        windowManager.addView(btn, params);
        console.log("✅ 原生免权限悬浮球已成功挂载至游戏顶层！");
    });
}
```

## 三、 防触控穿透的核心：`FLAG_NOT_FOCUSABLE` 与事件拦截

在开发游戏 UI 时，最常遇到的体验 Bug 是：**玩家在点击或拖动悬浮窗时，悬浮窗底下的游戏卡牌也被误触点击了！**

彻底解决触控穿透的关键在于理解 Android 的事件消费机制：

1. **`return true` 的消费契约**：
   - 在 `OnTouchListener.onTouch` 中，必须明确返回 `true`；
   - 这告诉 Android 视图分发流水线（`ViewRootImpl`）：**当前触控事件已被本视图完全消费完毕，停止向下递归传递**。底层 Unity 的 `SurfaceView` 将根本接收不到这次点击坐标。
2. **`FLAG_NOT_FOCUSABLE` 的平衡艺术**：
   - 如果不加该标志，悬浮窗会全局抢占所有输入事件，导致游戏原本的触控操作全部失效；
   - 加上 `FLAG_NOT_FOCUSABLE` 后，系统会自动进行精准分流：**落在按钮范围内的事件由按钮消化；落在按钮范围外的空白区域原样交给 Unity 处理**。
