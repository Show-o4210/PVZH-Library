# 04. 签名持久化与无缝覆盖安装规范

在 Android 系统的安全模型中，应用的包名（Package Name）和**数字签名证书（Signing Certificate）**共同构成了应用的绝对唯一身份。

很多开发者在开发初期习惯性地使用 Android SDK 自带的临时 `debug.keystore`，或者每次打包时随手用工具生成一个临时证书。这会导致一个灾难性的后果：

> ❌ **“更新不兼容”惨剧**：  
> 当玩家安装了你发布的 Mod v1.0，几天后你修复了一个 Bug 并发布 v1.1。如果两次打包的签名证书不一致，Android 系统在安装时会坚决拒绝安装，并弹窗提示：  
> **`INSTALL_FAILED_UPDATE_INCOMPATIBLE: Existing package signatures do not match newer version`**  
> 玩家为了体验新版本，不得不将旧版本完全卸载。而卸载应用会**一并抹掉玩家本地所有的卡组、对战记录与偏好设置**！

为了保证 Mod 能够像官方应用一样支持**无缝覆盖升级（`adb install -r`）且绝不丢失玩家数据**，我们必须建立一套工业级的签名持久化规范。

---

## 一、 建立长期固定的权威发布密钥库（Keystore）

在发布正式版本之前，必须且仅需生成一次**4096 位的 PKCS12 长期发布密钥库**。

使用 JDK 自带的 `keytool` 命令行工具生成：

```bash
keytool -genkeypair \
    -alias pvzh-mod-release \
    -keyalg RSA \
    -keysize 4096 \
    -sigalg SHA256withRSA \
    -validity 10000 \
    -storetype PKCS12 \
    -keystore release.p12 \
    -dname "CN=PVZH Mod Release, OU=Modding Community, O=Community, L=Local, ST=Local, C=CN"
```

### 关键参数解析：
- **`-validity 10000`**：证书有效期长达 10,000 天（约 27 年），彻底避免在 Mod 生命周期内证书过期；
- **`-keysize 4096`**：采用超高强度的 4096 位 RSA 密钥，完全满足现代 Android 14~16+ 严苛的安全合规标准；
- **`-storetype PKCS12`**：行业标准的现代密钥库格式（`.p12`），具备极高的跨平台兼容性。

> [!IMPORTANT]
> 🔒 **核心密钥资产保管原则**：
> 生成的 `release.p12` 文件必须妥善保存在安全的私有目录中，**严禁将其提交到公共 Git 仓库**。以后的所有 Mod 版本（v1、v2、v3...）均必须使用这同一份文件进行签名。

---

## 二、 4 字节内存对齐实战（`zipalign`）

在执行现代 Android 签名之前，APK 压缩包内的所有文件必须先经过 **`zipalign`** 进行 4 字节（32 位）边界对齐。

### 为什么必须对齐？
Android 系统在加载 APK 内的原生 SO 库和未压缩资源时，使用底层的 `mmap` 系统调用直接映射内存页。如果文件起始偏移不是 4 的倍数，系统在读取时会产生巨大的额外内存拷贝开销，甚至在 Android 11+ 上直接被系统拒绝安装。

执行对齐命令：

```bash
# 语法: zipalign -p -f -v 4 <未对齐输入.apk> <对齐后输出.apk>
zipalign -p -f -v 4 PVZH_Mod_unsigned.apk PVZH_Mod_aligned.apk
```

- **`-p`**：对 SO 动态库按照内存页边界对齐；
- **`-f`**：如果输出文件已存在则强制覆盖；
- **`4`**：对齐基数（32 位边界）。

## 三、 使用 `apksigner` 执行全方案数字签名

很多老旧教程依然推荐使用 `jarsigner`，但 `jarsigner` 仅支持极其古老落后的 **v1 签名（基于 JAR 文件的签名）**。

现代 Android 系统（特别是 Android 11+）强制要求必须包含 **v2 签名方案（APK Signature Scheme v2，整包二进制哈希树签名）**。因此必须使用 Android SDK 官方的 **`apksigner`** 工具进行签名：

```bash
apksigner sign \
    --ks release.p12 \
    --ks-key-alias pvzh-mod-release \
    --ks-pass pass:你的密钥库密码 \
    --out PVZH_Mod_release.apk \
    PVZH_Mod_aligned.apk
```

## 四、 签名验证与权威指纹校验

在将构建好的 APK 交付给测试设备或玩家之前，必须执行严格的离线签名校验：

```bash
apksigner verify -v --print-certs PVZH_Mod_release.apk
```

控制台若输出如下结果，代表签名完全合格：

```text
Verifies
Verified using v1 scheme (JAR signing): true
Verified using v2 scheme (APK Signature Scheme v2): true
Verified using v3 scheme (APK Signature Scheme v3): true
Number of signers: 1
Signer #1 certificate DN: CN=PVZH Mod Release, OU=Modding Community, O=Community, L=Local, ST=Local, C=CN
Signer #1 certificate SHA-256 digest: 845924ff7fe54b5c428e74da8fe5cf8f61d7e7db5205d003ab517c5bc07992d3
```

### 重点核验指标：
1. **`v1 / v2 / v3 scheme` 均为 `true`**：确保从 Android 7.0 到最新的 Android 16 全版本通用兼容；
2. **`Signer #1 SHA-256 digest`**：请记录下这个 64 位的哈希指纹。未来每次发布新版本时，比对该指纹是否与初版**完全一致**。只要指纹一致，用户就可以直接执行 `adb install -r` 享受完美的平滑升级体验！
