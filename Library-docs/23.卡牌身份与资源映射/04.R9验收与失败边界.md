## 1. 对应哪一次开发

证据属于2026-10-19完成的独立R9候选，目标为原版卡修改、新GUID复用原版资源及对应文字。基于R8 RC2开发，保留R7/R8、Mod2和旧PVZHUABE；不将结果混入第22章最初的32例API/离线评测或六份卡牌25项设备抽测。

| 项目 | 指纹/范围 |
|---|---|
| 最终候选 | `r9-cards-rc4`，游戏1.67.8 ARM64 |
| APK SHA256 | `a5b0baf75b47cf5f2cc6ac1f301fe3fc5b6f6398ca2994ceb537160d1a691f32` |
| 设备环境 | 已root Pixel6，Android16，当前manifest11064 |
| 手机实际读取 | `cards/card_data_1`、`loc/cn_9`、`data_assets_36` |
| 在线模型 | `deepseek-flash`，3次请求，均为手机请求、手机编译、UI预览后保存 |

完整产品和原始日志保留在工作区`pvzh-launcher/native-r9`。本库只提供[筛选摘要](验收摘要.json)，记录来源文件SHA256及必要字段，不打包APK、Bundle、签名材料、账户日志或完整调试服务。

## 4. 资源与文件证据

手工项目注册4个别名，三个寻址方法合计实际映射28次；最终API项目注册3个别名，映射22次，两组错误列表均为空，带画面动画队列正常结束。这是实际寻址与加载流程证据，不只是静态写了映射表。

API第一版只改变原版326，并新增900001/900002/900003；第二版卡体只改变900001；第三版仅改变两条简介Key和900002短说明Key，卡牌Bundle字节不变。三个版本未生成关卡资源，身份和其他卡保留。

多Mod顺序检查按胜出card_data重新生成别名。最后恢复原先Mod2的内容、顺序、勾选及三份缓存哈希，测试Mod保留为关闭状态，账户未清除，R9保留安装。官方Manifest JSON和bin前后哈希一致；本轮不能据此验证它们的加载优先级。

## 5. 保留失败，说明修正

| 失败 | 原因与处理 |
|---|---|
| 初始检视文本读取失败 | 调试访问器请求了不存在的Description字段；改按实际装箱结构及本地化Key读取，另开新证据 |
| 环境打出被拒绝 | 测试选了高地0号线；合法性检查正确，改到平地1号线，没有绕过出牌规则 |
| 资源适配TypeError | 错误定位到字符串缓存调用，改用索引对象缓存，另次实际映射及队列检查通过；不推断JavaScript Map在所有环境失效 |
| API第一次遗漏简介 | 结构和技能编译通过，语义未完整满足，不计为完整自然语言成功 |
| API第二次把简介写进短说明 | 明确简介/技能短长说明字段含义，第三次真实请求修正，未手改计划冒充模型正确 |

原始失败记录与最终PASS分开保存。70是三组最终游戏检查总数，不是“所有尝试均成功”；3是本轮真实模型调用次数，也不是“3个请求首次语义全对”。

## 6. 明确保留的边界

- 新GUID收藏、组牌、库存持久化未实现；能抽入并打出不证明这些系统已登记。
- 原版能力合同未覆盖任意组合；Mod2私有技能生成未开放。非单位自定义触发限受约束打出效果，复杂能力可以按合同保留/复制。
- 保存需完整重启，多Mod整文件优先，不自动合并卡表/中文。只有具备card-assets-v1适配的加载端才承诺这套新身份资源寻址。
- 没有新增图片、音频；音频路径虽纳入适配，没有单独播放验收。真正新增美术、Manifest/bin写入、所有动画逐帧表现和全部关卡通关未测。
- 只有DeepSeek进行了本轮真实提供商测试，其他兼容接口不能由此称为已实际验证。

授权密钥仅在会话内存；测试后的进程重启清除会话，临时反向端口移除。此次归档不读取或复制凭证，不导入设备备份。
