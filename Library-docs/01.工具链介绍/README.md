# 01. 工具链介绍

工欲善其事，必先利其器。在进行 PVZH 的 Mod 制作与数据修改前，搭建一套高效、稳定的工具链能让你事半功倍。

本章节将工具分为**基础资源工具**、**工程还原工具**、**移动端/在线辅助工具**以及**高阶逆向工具**四大类。

---

## 一、 基础资源解包与修改工具

### 1. 资源预览与提取：AssetStudio
- **用途**：用于预览、搜索以及提取 AssetBundle 中的贴图（Texture2D / Sprite）、音频（AudioClip）及确定卡牌信息。
- **推荐版本**：建议优先选择**社区 MOD 强化版本**（通常包含了更多的结构解析修复与批量导出优化，比官方原版更好用）。

### 2. 资源修改与重新打包：UABEA (Unity Assets Bundle Extractor Avalonia)
- **用途**：标准的图形化 AssetBundle 修改与打包工具，用于替换贴图、修改数据块及导出/导入 Raw/Dump 数据。
- **注意事项**：老旧版本的 UABE 无法解包新版 Unity（如 PVZH 使用的 2022.x 系列）的资源包，**必须使用 UABEA** 或支持 2022.x 的版本。
- **新手教程**：详见 [02. UABEA 基础使用指南](02.UABEA基础使用指南.md)，快速掌握文件打开、Info 视图操作、Dump/Dat 数据修改及 Plugins 贴图替换。

### 3. 高阶精准修改：UnityPy (Python)
- **用途**：基于 Python 的 Unity 资源包处理库。
- **特点**：对于熟练掌握 Python 的高阶玩家，UnityPy 在批量自动化处理、数据提取以及文件重建的**准确度上高于 UABEA**，但需要编写代码操作，门槛较高。

---

## 二、 工程还原与引擎级修改

### 1. 资源还原：AssetRipper
- **用途**：将编译打包后的 AssetBundle 逆向还原为标准的 Unity 工程格式。
- **主要场景**：通常配合 Unity 引擎使用，用于提取复杂的场景、动画或完整的预制体（Prefab）结构。

### 2. 核心编辑：Unity 引擎 (Unity Editor)
- **用途**：高阶 Modder 的必备利器。
- **特点**：直接在 Unity 引擎的视窗中调整场景、材质、动画和组件参数，远比在十六进制编辑器中手动修改或改动 `dump` 参数要高效且直观得多。

---

## 三、 移动端替换与在线辅助工具

### 1. 文件管理：MT管理器（Android）
- **用途**：用于在安卓设备/模拟器中直接替换 `/storage/emulated/0/Android/data/com.ea.gp.pvzheroes/files/cache/bundles/...` 目录下的缓存资源包。
- **环境要求**：通常**不需要 Root 权限**即可完成替换。

### 2. 手机端可视化修改与在线工具
如果不想在电脑端进行复杂的解包操作，或者希望在手机端直接改版，推荐使用以下工具：
- **在线 Web 工具站**：[https://pvz-h-tools.onrender.com/](https://pvz-h-tools.onrender.com/)
- **说明**：由社区开发者（**休切尔**）本人长期维护，完全免费且公开开源，提供了便捷的可视化修改与数据生成服务。

---

## 四、 高阶重度玩家工具（源码与数据分析）

> [!WARNING]
> 本节工具门槛较高，**不建议手机端用户尝试此类深度修改**；同时对于普通 Modder，**不推荐耗费精力去玩动态调试**。

### 1. 源码导出：Il2CppDumper
- **用途**：将安卓 APK 中的 `libil2cpp.so` 与 `global-metadata.dat` 联合解析，导出包含完整 C# 类、函数、数据字段及内存偏移量的 `dump.cs` 文件，用于查阅游戏底层底层逻辑。

### 2. 文本与代码编辑器
- **重型代码/大型工程**：推荐使用 **VS Code** 或 **Antigravity IDE**，提供强大的语法高亮、全局搜索与符号跳转。
- **日常轻量修改**：一律推荐使用 **Sublime Text**，轻量且响应迅速。

### 3. 十六进制编辑器 (Hex Editor)
- 建议直接使用网页端 Hex 工具，或选择任意顺手的本地 16 进制编辑器（Sublime Text 也支持十六进制查看，但在空格区分与特定搜索上体验稍弱）。

---

## 五、 测试环境与模拟器选择

在电脑端调试 Mod 时，推荐搭建安卓模拟器环境：
- **首选推荐：雷电模拟器**（在 PVZH 的 Mod 调试、文件读写与运行稳定性上表现最好）。
- **其他模拟器**：MuMu 模拟器、逍遥模拟器等在特定情况下可能存在兼容性或文件权限小问题，不作为第一推荐。
