# 02. UABEA 基础使用指南

**UABEA (Unity Assets Bundle Extractor Avalonia)** 是目前修改 PVZH（Unity 2022.x 引擎）AssetBundle 资源包最核心、最通用的图形化工具。

本篇教程以最直观的步骤，讲解如何用 UABEA 打开游戏资源包、进入 `Info` 视窗以及使用 `Dump`、`Dat` 文本改动与 `Plugins` 贴图替换。

---

## 一、 打开文件 (Open & Decompress)

1. 双击运行 `UABEAvalonia.exe`。
2. 点击菜单栏 **`File` -> `Open`**，选择游戏目录下的资源包（如 `cards/card_data_5` 或贴图包）。
3. **解压提示 (Decompress)**：
   - 若弹窗提示 *"This bundle is compressed. Do you want to decompress it?"*，点击 **`Memory`**（在内存中直接解压，更快捷）或 **`File`**（解压另存为新文件）。

---

## 二、 进入 Info 视窗 (Info Window)

1. 文件加载完毕后，在主界面列表框中选中你需要修改的 Assets 条目。
2. 点击右侧的 **`Info`** 按钮。
3. 此时会弹出 **Asset Info** 独立视窗，里面包含了该 Bundle 内所有的资源节点（如 `TextAsset`、`Texture2D`、`MonoBehaviour` 等）。

> [!TIP]
> 可通过视窗上方菜单 **`View` -> `Search by name`** 输入名称快捷定位目标资源；也可以点击 `Type` 表头按资源类型排序。

---

## 三、 常用导出与修改操作

### 1. 修改卡牌数据/配置表 (Dump & Raw/.dat)

常用于修改 `TextAsset`（如 `card_data` JSON 文本）：

- **导出可读文本 (Export Dump)**：
  - 选中目标资源节点 -> 点击右侧按钮 **`Export Dump`** -> 另存为 `.txt` 或 `.json` 文件。
  - 使用 VS Code、Sublime Text 或 Notepad++ 打开并修改数据。
- **导入修改文本 (Import Dump)**：
  - 修改完成后，在 UABEA `Info` 视窗中选中对应节点 -> 点击右侧按钮 **`Import Dump`** -> 选择修改好的文本文件导入。
- **原始二进制修改 (Export Raw / Import Raw)**：
  - 点击 **`Export Raw`** 可保存为 `.dat` 原始数据块；修改后通过 **`Import Raw`** 覆盖。

### 2. 贴图素材替换 (Plugins)

常用于修改 `Texture2D`（如卡牌贴图、精细 Sprite）：

1. 在 `Info` 视窗中选中类型为 `Texture2D` 的节点。
2. 点击右侧的 **`Plugins`** 按钮。
3. **导出图片**：选择 **`Export to .png`** 导出保存为 PNG 图片进行修改。
4. **替换图片**：选择 **`Edit`**（或 `Load / Import .png`）-> 选择修改好的 PNG 图片 -> 点击 `OK` 确认导入。

---

## 四、 保存与导出 (Save)

> [!CAUTION]
> **切记要“双重保存”！仅在 Info 窗口点击保存是无法写入磁盘文件的。**

1. **保存 Info 修改**：在 `Info` 视窗中修改完毕后，点击 `Info` 视窗菜单栏 **`File` -> `Save`**（关闭 `Info` 视窗）。
2. **保存导出 Bundle**：返回 UABEA 主界面，点击主界面菜单栏 **`File` -> `Save`**，选择保存路径并保存为一个新的 `.bundle` 文件。
3. 将保存得到的新 Bundle 文件复制替换到模拟器/设备的对应资源目录下即可。

---

## 避坑小结

- **无法保存覆盖**：保存时不要直接覆盖正在被 UABEA 打开的原文件，先另存为新文件（如 `card_data_5_mod`），关闭 UABEA 后再重命名覆盖原文件。
- **文件丢失 classdata.tpk**：若打开文件报错，请确保 UABEA 程序同级目录下存在 `classdata.tpk` 数据库文件。
