# 启动器界面命名与定位

外观编辑部分适用于 r-2-27 及继承该流程的 r-2-28 RC1。手机关卡编辑从 R58 RC3 起使用下表。其他界面编号继承 R48 RC2，各版本的手机功能与验收见[版本能力与验收](05.当前版本能力.md)。

你可以直接说“修改 **E05 积木画布** 的添加入口”“把 **S03 官方资源** 的提示缩短”，无需记源码名称。编号随界面保留；以后改名或调整位置时更新本表，不把旧编号分配给其他界面。编号用于沟通，不是屏幕上新增的按钮，也不是 Android 控件 ID。

本页移植上游R48的123个稳定界面编号，供描述问题与维护定位。启动器完整源码、APK、运行时和本机交付记录不随本资料库提供；表内类名、方法名、控件标识及载荷路径是上游参考标识，不是要求读者拥有的本地文件。

表中的“定位”供维护者检索。`manual_*`、`chat_*` 等是实际控件的无障碍标识；后缀含卡牌、会话或节点路径时动态生成。通用确认框按所属页面称呼，例如“E05 删除积木确认框”。

r-2-55 RC1 开发包在 Android 11 及以上的「游玩」页提供「离线游玩」开关。开启后，两张启动卡片会在 Android 拒绝网络访问的独立进程中启动游戏，手机可以保持联网。要使用游戏的联网功能，先从最近任务关闭离线游戏，再回到「游玩」关掉开关并重新启动。首次尚无有效缓存时，先完成一次普通启动。维护定位为 `launcher_local_resource_startup`。

编辑器区域名统一如下：

- **编辑器顶栏**：返回、卡牌名称、撤销图标、重做图标。返回统一处理当前面板与层级。
- **编辑器主操作栏**：基础、词条、积木、保存四个按钮。
- **编辑器状态条**：已保存、未保存、保存失败等反馈文字。
- **积木插槽**：某块内部允许放入子积木的位置；“插槽标题”和“插槽内积木”分别描述。
- **选中积木**：长按后高光描边的操作对象；拖动时另有落点反馈。
- **组件内部展开区**：组件块中的“内部积木 ▾／▴”；只展开该组件的原生内部结构，不是切换到已删除的紧凑布局。普通原子节点的插槽直接展开。
- **列表标签**：E13 中的一项字符串；这里的种族、tags、属性图标仍是各自原字段，三者没有合并。

“保存”对玩家只有一个概念：写入当前 Mod。内部工程是实现细节，不再作为单独按钮或要求玩家掌握的步骤。原始卡牌编辑、JSON 对象／列表编辑、完整展开／紧凑切换、手动工程导入／导出均已从 R45 玩家界面移除；既有未知数据继续保留。

## 8. 卡牌交互媒体

G 系列是游戏原生界面上方的 Android 媒体界面，与 F01 悬浮球、W14 上下文浮层和原版 X05 对局界面分别命名。它只由本次实际获胜卡表来源 Mod 的明确媒体声明启用；没有登记的原版／其他 Mod 不显示。图标出现与玩家点击是两个动作，出现本身不打开网页或播放视频。

| 编号 | 标准名称／常见叫法 | 进入路径与范围 | 维护定位 |
|---|---|---|---|
| G01 | 卡牌交互媒体浮层／媒体卡片 | 已登记卡牌的普通原生出牌事件通过后，出现在游戏画面上方；每个登记项一张媒体卡片，最多同时三张 | `NativeModMedia.present()`；单张卡片为 `media_panel_<entryId>`；外层容器本身没有独立无障碍 ID |
| G02 | 媒体动作图标／云·原神图标 | G01 中的可点击图片；点击后按登记打开默认浏览器或播放视频 | `present()` 的 `ImageView` 和 `open()`；`media_action_<entryId>` |
| G03 | 媒体关闭按钮 | G01 右上角 ×；只关闭该张媒体卡片，不触发其链接或视频 | `present()` 的关闭按钮；`media_close_<entryId>` |
| G04 | 视频播放弹窗 | 只有登记 `play_video` 的 G02 被明确点击后出现；支持登记的 HTTPS 视频或经过指纹核对的本地视频 | `NativeModMedia.playVideo()`；播放器子控件 `media_video_player`，标题取登记项名称；关闭按钮文字“关闭” |
| G05 | 视频播放控制条 | G04 的播放／暂停、进度等系统视频控制 | Android `MediaController`；无本项目自定义稳定 ID，以新鲜 UI 树实际控件为准 |
| G06 | 媒体浏览器选择器 | G02 为网页动作且系统没有可直接采用的默认浏览器时出现；有默认浏览器时直接进入 X04 | `NativeModMedia.open()`；Android chooser 标题“选择浏览器”，无本项目自定义控件 ID |

这里的 `<entryId>` 是登记的 `mod_id/action_id`，无障碍标识将其中 `/` 替换为 `_`，其他允许的字母、数字、点号、短横线及下划线保留。招笑版胖墩的登记为 `mod2/overstuffed-cloud`，因此对应：

- 媒体卡片：`media_panel_mod2_overstuffed-cloud`。
- 动作图标：`media_action_mod2_overstuffed-cloud`。
- 关闭按钮：`media_close_mod2_overstuffed-cloud`。

G04/G05 是复用视频能力的条件界面，不表示招笑版胖墩当前动作是视频；该卡登记的动作是点击后打开云·原神官网。外部浏览器中的网页仍称 X04，不将官网页面或 Android 选择器当成启动器自己绘制的新页面。页面名称和控件 ID 的登记也不代表这些步骤均已完成实机验收。
