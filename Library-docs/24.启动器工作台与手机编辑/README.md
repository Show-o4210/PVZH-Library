## R42–R51 与正式 v1 历史阶段

| 阶段 | 本轮阅读时应理解的变化 |
| --- | --- |
| R42 | 卡牌快速／专家模式第一版，关卡共用流程 |
| R43 | 资源确认后台队列；当时自动触发策略已由后续替代 |
| R44 | 14类组件配方与分层积木编辑 |
| R45 | 玩家编辑器减法、开关／单项输入、完整资源检查纯手动 |
| R46 | 招笑版出牌图标与显式点击网页／视频能力 |
| R47 | 独立文言文中文包内置，默认关闭、首次置顶 |
| R48 | 手机字号、触控、选中反馈、位置／滚动保留和内部默认展开 |
| R49 | 共用动态能力目录，运行支持与AI开放分别展示 |
| R50 | 独立只读项目留言／名单数据、内置回退与后台读取 |
| R51 | H07关于独立，H03仅联系支持；两页返回首页 |
| 正式v1 | 对外v1、内部R51、独立发布编号100001；开发默认development，正式显式stable，普通公告保留 |

保存的Mod与游戏实际加载内容是两份状态，继续采用完整退出并重新启动后的加载流程，不承诺热更新。手动组件、AI开放工具和运行扩展分别说明；手机编辑器与库内Python工具不共享菜单或接口合同。

本机／产物、真实AndroidUI、原引擎、正式对局、真实模型与视听各自留证。R48已有手机UI历史验收；其后的纯展示／数据与发行增量不能借此宣称重新实机通过。具体成功、失败与未测按05和06理解，不从一层PASS外推全部手机、技能、关卡或成本。
