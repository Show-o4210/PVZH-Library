# 资源检查、交互媒体与文字包

这些能力截至R48继承已有实现。不同版本的历史策略必须按日期理解：R43曾将自动资源准备移到独立后台；R45依用户要求改为纯手动完整检查，R48沿用R45策略。

## 官方资源纯手动检查

普通启动复用上次成功准备记录，仅核对固定7份元数据和3项核心目标，不联网核对官方新版本，不遍历全部2880资源目标。记录缺失、资源身份改变、核心目标缺失或事务未完成时提示手动检查；Mod实际部署的文件安全与事务守卫仍保留。

完整官方检查、同步与修复从设置中的“官方资源”手动触发。R45实机手动结果为官方无变化、2880项复用、0下载；普通UI原版入口进入主界面时没有重新全量检查。这个结果不证明未来官方版本、所有网络环境或所有资源损坏情况。

非核心包不在每次启动逐一核验，缺失／损坏需要主动检查。资源检查的网络行为与游戏联网、公告等其他请求分别统计。未做同条件启动时间对照，不能宣称某个加速百分比。

## 卡牌交互媒体

R46建立可复用的出牌媒体声明，支持图标出现后由玩家明确点击打开HTTPS网页，或播放登记的本地／HTTPS视频。媒体仅从实际采用的卡表来源Mod读取，受资源指纹及能力许可约束；原版或被其他卡表覆盖的同GUID不能自动继承媒体动作。显示图标本身不自动打开网页或视频。

招笑版胖墩僵尸（GUID495）是当前案例：旧三组技能移除，真实手牌打出后显示云·原神图标，再点击使用默认浏览器进入官网。其余卡牌及已有音乐／法老内容保持。此案例是Android媒体扩展，不是向游戏卡表写入一个不存在的原生技能类型。

R46已经分别验证普通合法出牌、图标、浏览器点击与返回、原版负例，以及本地无声视频的可见播放／完成／关闭。未验证任意在线视频、声音、所有编码、远程对局或全部出牌边缘场景。AI工具尚不能直接创作媒体声明。

音乐使用已登记Mod曲目与共享生命周期；规则登记、实际播放器状态、RTPC和听验属于不同层级。相关历史资料见[本地背景音乐与共享生命周期](../21.语义调试与技能扩展实战/09.本地背景音乐与共享生命周期/README.md)。

## 文言文内置包

R47将既有full-v2中文成品原字节封装为独立的“文言文中文包”，R48继续内置。首次内置导入放在列表最前，默认关闭；之后保留玩家排序、启用与移除选择，不在每次启动强行置顶。R48实机验证了首次导入的位置和关闭状态。

它替换游戏内完整简体中文资源，不修改启动器文字或实际技能。原版游戏入口忽略全部Mod；体验原版玩法的文言翻译应只启用文字包，再进入所选Mod组合。

多Mod采用整资源族优先级。文言包基于官方卡牌说明，与招笑版等技能修改Mod同时开启时，靠前的中文包可能覆盖玩法Mod的定制文案。已知招笑370条定制说明被覆盖，且full-v2缺少其两项自定义键；例如胖墩仍可能显示原版旧说明，而实际图标／跳转技能照常运行。需要准确技能说明时关闭文字包，或将玩法Mod放在其前面。本版不自动拼接或补译不同玩法Mod的中文。

R47完成10783键、标记及Bundle结构的离线核对；R48确认内置导入行为。所有游戏页面的文言排版、字体和技能文案组合没有逐页实测。原翻译工作流见[文言中文包实战与验收](../03.本地化说明/05.文言中文包实战与验收.md)。
