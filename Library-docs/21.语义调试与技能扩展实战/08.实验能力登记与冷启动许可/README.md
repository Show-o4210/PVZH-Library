# 实验能力登记与冷启动许可

本节记录2026-10-20 Android启动器R12的后续实践：把Mod2既有私有技能整理成全局能力包，分开登记“运行时可执行”和“AI可编写”，再由启动器与悬浮窗共用设置。它没有重写第06节R19或第07节R25的历史统计，也没有升级本库公开Python原版制卡工具的合同。

R12使用 `r12-capabilities-1` 登记，运行部分沿用PVZH 1.67.8 ARM64的既有23项规则。能力的许可与资源、卡牌实际携带的规则、原生Hook安装结果必须分别核对。启用扩展不会自动给所有卡增加效果。
