## 本章确认了什么

R19将旧舍弃名单中的17张技能卡接入运行时，共14类扩展规则；合并后有99张原卡发生改变，保留656个定义及5个内部副本。另修97与547的原生配置，并处理咖啡墓碑保留、87现身及106次轮扣阳光的具体边界。

六组技能套件共127条检查通过；伞叶专项与交互逐笔核对321笔伤害，其中5笔零伤害。另有8项带渲染队列检查、原版17项接口／整局回归、原版规则隔离及资源门卫8项交付检查。完整映射见[实现覆盖](06.R19实现与验收记录/implementation-coverage.md)，归档后的机器摘要见[R19验收摘要](06.R19实现与验收记录/R19验收摘要.json)。

2026-10-15用户反馈游戏没有闪退。这是用户对游戏运行情况的反馈，不替代逐项技能或所有初始牌组的验收，也不撤销已经记录的调试建局异常。

## 没有确认什么

- 99张卡的全部组合、AI独立预测模型及全部美术表现没有穷举验证。
- 调试建局在连续温重开及一次含601／202的初始牌组冷建局中出现过原生访问异常；两秒或五秒等待不是根治，具体原生子调用未定因。
- 普通初始牌组再用 `give` 加入测试卡的完整改版对战已完成。不能将它改写为含新卡初始牌组初始化也通过。
- 原版终局 `LoseEffect` 会阻止最后的攻击结束书签继续执行；终局留下的scalar metadata不能误报为对局未结束，也不能声称旧局已彻底清理。
- 本轮没有新增音频、模型或专属动画。未实现严格旧局销毁屏障和按代长期GC根回收。
