# 不死法老实现

用户确认“攻防相等”表示每个单位变形前后当前攻击和当前生命分别相等。不是统一成一个固定身材，也不保留旧最大生命和旧伤害记录。例如原7攻、最大13血、已伤3，变形后为7攻10血、伤害0。费用、种族、原技能、装甲等采用目标卡本身的定义。

不死法老GUID201保留6费4/6与装甲1，原来的英雄最低生命1技能被替换。目标为豌豆射手10、普通僵尸50；当前招笑版这两张定义与原版相同。自身排除，英雄、手牌、牌库和环境不纳入单位变形。

一次自身PlayTrigger发出私有规则1026：先快照所有其他场上单位ID、阵营、owner、lane与当前攻血；再以真实指针/模型绑定的内部Grant逐目标调用原router所持TransformSystem的CreateCard(Effect,guid)，最后读取新修正量并排原生SetStatEffect及StateCheck。系统由原EffectRouter的handler委托定位，严格核对其Entities属于当前模型，不另造System或增加Hook。它继续走原生重置、位置、owner和TransformedCard记录路径，不只改外观或直接写GUID。视觉动画另算验证范围。

规则登记为`pvzh.rule.transform_others_keep_current_stats` version1，受全局扩展许可与原版入口守卫限制。1026首版仅运行能力，不声称AI自由配方已开放。音乐独立使用已有1024，曲目由本Mod `audio/music.json`登记，namespace=mod2 / track_id=liukun_theme / slot=8952476。

音频是用户提供的48kHz双声道16bit PCM，111.513583秒、21,410,756字节；SHA256 `798a0f0dc92db48958c8b5661af8f19a31cef48f79916d455b9d50c604b599f3`。循环播放，gain1，并继续乘以用户游戏音乐偏好；原Wwise BGM只临时静音，系统媒体流、SFX及画质不改。设置→技能扩展需开启扩展技能包和Mod音乐，完整重启生效。

## 原生子效果的验证合同

私有规则处理器中生成的子效果不应照抄原descriptor的EffectEntityId。原生EffectEntityValidator先重新验证原PlayTrigger，之后才按RequiresTargetValidation检查目标。仅关闭目标检查仍可能让子效果被悄悄取消。

本模块已经自行精确快照并核对场上目标，续接又绑定真实effect指针、model与generation，所以新子效果使用`EffectEntityId=-1`、`RequiresTargetValidation=false`；SourceId与SpringboardId仍为真实法老。外层启动许可、已知规则、原版模式和实体容器守卫不放宽。没有新增原生Hook，没有递归泵队列，也不改其他技能的验证方式。

## 来源与检查层次

R24 RC5冻结为来源，原游戏SO/Gadget ELF不改。R25只补1026到原Grant分派与登记；音乐机制仅同步registry revision。原包659定义、两个CN记录、Bundle对象、WAV与manifest经独立回读，80项静态检查通过；最终host87项仅证明协议、边界和池所有权。

RC1实机发现子效果被旧descriptor验证取消，真实WAV已经播放，但变形未执行；保留语义FAIL。RC2只构建，未安装/实测。RC3修正子效果合同后植物成功，但普通僵尸50带原版cheats标签，被Subset Finder强制NotCheats筛掉；该版语义FAIL保留。

RC4改为原生指定GUID的CreateCard入口，不删除50标签，不使普通僵尸混入其他随机卡池。基础52项通过，但正环境出现5/11被再次+5/+5为10/16，语义FAIL保留。

RC5复用既有router owner观察原生ContinuousEffectsCompleteEffect，确认同router/model后按已经生效的连续修正校准一次。负生命Buff在这个窗口使本次正生命快照目标暂时归零时，响应效果先于CheckDeath修复HP，完成校准后立即解除观察。没有增加Hook，没有取消正常死亡，没有持续把属性钉在快照值。

RC5真实基础54项、正环境78项、负环境79项、原版10项均通过。正环境3种、414自光环与墓碑同场，负环境全蚀489伤后1血和树液之地460负攻同场；负场景实际触发一次HP保护，最终9/9个目标正确、pending0/errors0。后续Buff与致命伤按原生效果生效；法老Damage2仅掉1确认装甲1。原版入口保留原201英雄最低1血能力且不变形、不播放Mod音乐。
