# 原版场景能力目录

本目录整理原版已有的场景规则，供关卡设计时选择和讨论。以 `资源/index_new2.json` 中 `UUID=BoardAbilityView` 的59条为入口，再核对原版卡表的完整效果实体及使用这些规则的关卡中文。来源为当前项目冻结的PVZH 1.67.8卡表及11064关卡/CN底稿。

59条全部带有 `BoardAbility` 组件；它们对应57份不同的效果实体结构。原版1065份关卡配置中，45条被直接引用，14条未发现直接引用。这里的功能名便于查阅而拟定；这些卡共用 `BoardAbilityView`，没有各自独立的卡名/shortDesc/longDesc。

**本目录是源数据与文案核对结果，尚未逐条实机验收。** “原版存在”“原关卡使用”和“R34工作台已开放”分别列出。R34当前只登记14条原样复用规则，且要求当前Mod保留对应原版卡定义；其余条目并未因此自动加入工作台。

表中路号为玩家习惯的第1～5路。**未引用**表示当前完整关卡底稿中没有直接挂载；仍保留原版定义，不据此判定没有效果。**R34**表示当前已登记的原样复用项。
