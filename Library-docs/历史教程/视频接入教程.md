# Unity 2D AssetBundle 纯手动 Modding 指南（Unity Editor + UABEA 版）

本指南提供了一套完全脱离 Python 自动化脚本、仅依靠 **Unity Editor** 与 **UABEA (Unity Assets Bundle Extractor Avalonia)** 进行手动修改的操作步骤。适用于快速验证、单包制作以及理解底层组件重绑定逻辑。

---

## 🛠️ 核心逆向工具准备
1. **Unity Editor**：建议使用与游戏大版本一致的版本（本项目建议 **Unity 2022.3.x**），并在 Build Settings 中将平台切换至 **Android**。
2. **UABEA**：用于直接查看和编辑 AssetBundle 内部序列化树（TypeTree）及二进制数据的工具。

---

## 📽️ 模改类型一：视频播放卡牌 Mod（手动制作步骤）

### 步骤 1：在 Unity 中制作“视频组件模板”
由于在 UABEA 中直接无中生有地拼写复杂的类型树参数极易出错，我们需要用 Unity 生成一份纯净的模板：
1. 打开 Unity，在场景中创建一个空 GameObject，命名为 `VideoTemplate`。
2. 为该物体添加 **VideoPlayer** 组件，参数配置如下：
   * `Source` $\rightarrow$ 选择 `URL`。
   * `Play On Awake` 与 `Loop` $\rightarrow$ 均勾选。
   * `Render Mode` $\rightarrow$ 选择 `Material Override`。
   * `Target Material Property` $\rightarrow$ 手动输入 `_MainTex`（**必须手动录入，不能保持空或 `<noninit>`**）。
   * `URL` $\rightarrow$ 填写真机播放路径：  
     `file:///storage/emulated/0/Android/data/com.ea.gp.pvzheroes/files/cache/bundles/files/video/card_video.mp4`
3. 为同一物体添加 **AudioSource** 组件，参数配置如下：
   * `Spatial Blend` $\rightarrow$ 拉到最左侧（值为 `0`，代表纯 2D 音效，防止距离过远无声）。
4. 返回 VideoPlayer 组件，将 `Audio Output Mode` 改为 `Audio Source`，并将刚才创建的 AudioSource 组件拖入 `Target Audio Sources` 数组的第一项。
5. 编写脚本或使用工具将此物体打包为 Android 平台的 AssetBundle，命名为 **`temp_video`**。

### 步骤 2：用 UABEA 提取组件“基因”
1. 运行 UABEA，打开生成的 `temp_video`。
2. 点击 **Info** 进入资产列表，找到 **Class 328 (VideoPlayer)** 和 **Class 82 (AudioSource)**。
3. 选中它们，分别点击右侧的 **Export Dump**，导出为 `VideoPlayer_dump.txt` 和 `AudioSource_dump.txt`。

### 步骤 3：向目标卡牌包注入新组件
1. 用 UABEA 打开你想修改的**干净原版卡牌 AssetBundle**。
2. 点击 **Info** 打开列表。由于目标包默认不含这两个组件，我们需要手动创建它们：
   * 点击上方菜单的 **Assets** $\rightarrow$ **Create Asset**。
   * 输入 Class ID `328` (VideoPlayer)，若 UABEA 询问是否添加类型树，选择“是”（若报错，可在后台保持打开 `temp_video` 以共享类型缓存）。
   * 将新生成的 VideoPlayer 对象的 Path ID 记录下来（例如我们在列表中看到的 ID，或将其指定为一个空闲的数如 `999999`）。
   * 同样方式，创建 Class ID `82` (AudioSource)，并记下其 Path ID（如 `999993`）。
3. 分别选中新建的 VideoPlayer 和 AudioSource，点击右侧的 **Import Dump**，导入步骤 2 导出的对应 `.txt` 文本。

### 步骤 4：在 UABEA 中手工完成 PPtr 链路重绑
我们需要通过修改 serialized 数据树将组件连成工作网：
1. **绑定 GameObject**：
   * 找到卡牌的身体 GameObject（例如鳄梨鳄的 `Guacodile_body_base`，记下其 Path ID，如 `2505563530246109078`）。
   * 选中新建的 `VideoPlayer` (999999)，点击 **Edit Data**，找到 `m_GameObject`，将其 `m_PathID` 设为身体 GameObject 的 Path ID，`m_FileID` 设为 `0`。
   * 选中新建的 `AudioSource` (999993)，做同样的修改，让它们挂载到同一个身体 GameObject 上。
2. **连接音视频组件**：
   * 展开 `VideoPlayer` 的数据树，找到 `m_TargetAudioSources` 数组，将其中唯一元素的 `m_PathID` 覆写为 `999993` (AudioSource)。
3. **绑定渲染目标**：
   * 在 `VideoPlayer` 数据树中找到 `m_TargetMaterialRenderer`，将其 `m_PathID` 指向卡牌身体的 `SpriteRenderer` 组件的 Path ID（如 `-824107450763009214`）。
4. **组件回挂 GameObject**：
   * 选中卡牌身体 GameObject（如 `2505563530246109078`），点击 Edit Data，展开 `m_Component` 数组，在末尾手动新增两个 PPtr 元素，分别指向 `999999` (VideoPlayer) 和 `999993` (AudioSource)。

### 步骤 5：网格 Quad 化重构（绕过 Tight 剪影裁剪）
若直接播放视频，视频会被原厂角色身体的抠图网格裁剪。我们需要将网格手工改造成 4 顶点的正方形 Quad：
1. **免除十六进制手改的小技巧**：
   * 在 Unity Editor 中新建一个纯白 2D Sprite，导入设置中将 `Mesh Type` 从 `Tight` 改为 `Full Rect`。
   * 打包此 Sprite 到模板包，使用 UABEA 导出这个 Full Rect Sprite 资源的 **Raw Data**。
   * 用 UABEA 打开目标卡牌包，找到卡牌身体的 Sprite 资源（如 Path ID `-7039357134312480387`），选中它，点击 **Import Raw** 将刚才的 Full Rect 替换进去。
   * 替换后点击 Edit Data，把里面的 `m_Name` 改回原厂名字，同时将底层的 `m_Texture` PPtr 指针改回指向包内原厂的 `Texture2D` 资源。
2. **尺寸调整**：在 Sprite 的 Edit Data 中，将 `m_PixelsToUnits` 的数值下调（如原版 `22.9` 改为约 `7.6`），即可等比放大视频画面。
3. **高度偏移**：双击打开身体的 Transform 组件，将 `m_LocalPosition.y` 的值增加 `8.0`（垂直向上挪移，使视频对齐卡牌框）。

## 🧍 模改类型二：纸片人重构 Mod（手动制作步骤）

### 步骤 1：在 Unity 中生成“五件套”基础模板
1. 在 Unity 中导入一张 1024x1024 尺寸的纯白 PNG 图片，导入设置设为 `Sprite`，`Mesh Type` 选择 `Full Rect`。
2. 将其在场景中挂载为 SpriteRenderer，并打包成 AssetBundle（命名为 `temp_papercraft`）。
3. 用 UABEA 打开模板包，导出这 5 个核心资产的 Dump：
   * `Sprite` $\rightarrow$ 导出为 `1001.txt`
   * `Texture2D` $\rightarrow$ 导出为 `1002.txt`
   * `GameObject` $\rightarrow$ 导出为 `1003.txt`
   * `Transform` $\rightarrow$ 导出为 `1004.txt`
   * `SpriteRenderer` $\rightarrow$ 导出为 `1005.txt`

### 步骤 2：在目标卡牌包中创建并注入五件套
1. 用 UABEA 打开目标卡牌 AssetBundle。
2. 使用 **Assets** $\rightarrow$ **Create Asset** 菜单分别创建 Class 213 (Sprite)、Class 287 (Texture2D)、Class 1 (GameObject)、Class 4 (Transform) 和 Class 96 (SpriteRenderer)。将它们的 Path ID 设定为固定值 `1001` 至 `1005`。
3. 选中这五个新建的项，分别点击 **Import Dump** 导入我们在步骤 1 中准备的对应 `.txt` 文件。

### 步骤 3：拼装五件套渲染链路
1. **替换立绘贴图**：选中 `1002` (Texture2D)，点击右侧 **Plugins** $\rightarrow$ **Edit**，导入您的 1024x1024 高清纸片人皮肤 PNG 图片并保存。
2. **连接 Sprite 与贴图**：打开 `1001` (Sprite) 的 Edit Data，将 `m_Texture` 的 `m_PathID` 设为 `1002`。将 `m_PixelsToUnits` 修改为 `75` 左右。
3. **GameObject 挂载组件**：打开 `1003` (GameObject) 的 Edit Data，修改 `m_Component` 数组，使其仅指向 `1004` (Transform) 和 `1005` (SpriteRenderer)。
4. **Transform 缝合至卡牌大根**：
   * 找到原包内 `m_Father` 指针为 0 的主 Transform 节点，记录其 Path ID（假设为大根 `555555`）。
   * 打开 `1004` (Transform) 的 Edit Data，将 `m_GameObject` 设为 `1003`，将 `m_Father` 设为 `555555`。`m_LocalPosition` 设为 `(0, 2.0, 0)` 代表局部高度抬高。确保 `m_LocalRotation` 重置为 `(0, 0, 0, 1)`（防止纸片人倾斜）。
   * 打开大根 Transform (`555555`)，在 `m_Children` 列表中添加一个子元素指向 `1004`。
5. **配置 SpriteRenderer 材质**：
   * 打开 `1005` (SpriteRenderer) 的 Edit Data，将 `m_GameObject` 指向 `1003`，将 `m_Sprite` 指向 `1001`。
   * 将 `m_Materials` 列表中唯一的 PPtr 材质指针，改写为原包内碎骨骼渲染器使用的材质 Path ID，以完全继承原厂 Shader 和 Stencil 裁剪效果。

### 步骤 4：物理净化与骨骼隐藏
1. 找到包内原厂碎骨骼所有的 `Texture2D` 和 `Sprite`，在资产列表中右键点击选择 **Remove** 进行物理删除。
2. **手牌保护警告**：如果包内含有 Container 路径类似于 `assets/ship/...` 的贴图，**绝对不能删除**，否则游戏内手牌卡牌立绘会丢失。
3. 找到原厂所有的碎骨骼 `SpriteRenderer` 资产，打开其 Edit Data，将 `m_Enabled` 设为 `0` (false) 进行禁用隐藏，防止在游戏画面中残留重合。

### 步骤 5：手动覆盖 Clip 动画 Dump
1. 找到包内全部的 `AnimationClip` 类型资产。
2. 准备已手工对齐节点的动画 Dump 文本（确保内部 `genericBindings` 的 `path` 均为代表 `"character"` 节点的路径 CRC32 哈希值 `2474291252`）。
3. 选中目标 Clip，点击 **Import Dump**，导入并替换动画曲线。

## 💾 封包保存与部署验证

1. 完成所有修改后，在 UABEA 主界面点击 **File** $\rightarrow$ **Save**。
2. UABEA 会弹出保存对话框，并要求选择压缩方式：
   * **极其重要**：必须选择 **LZ4** 或 **Original** 压缩保存！
   * **严禁选择 None**。不压缩保存将导致包体文件体积增大几倍，真机加载极慢且可能引发内存溢出崩溃。
3. 将保存得到的新包覆盖进真机相应目录下，并在 `video/` 目录下放置 MP4 视频，即可进入游戏启动测试。
