# 03. Android 高版本输入框滚动条空指针避坑

在将 Mod 安装包部署到搭载 **Android 15 / 16（API 35~36）** 的最新旗舰手机（如 Google Pixel 系列）进行真机实测时，很多开发者会遭遇一个令人匪夷所思的底层崩溃：

> ❌ **异常堆栈信息（Logcat 真实记录）**：
> ```text
> FATAL EXCEPTION: main
> java.lang.NullPointerException: Attempt to invoke virtual method
> 'android.widget.ScrollBarDrawable android.widget.ScrollBarDrawable.mutate()'
> on a null object reference
> at android.view.View.onDrawScrollBars(View.java:22396)
> at android.view.View.draw(View.java:23114)
> at android.widget.TextView.onDraw(TextView.java:8215)
> ```

更诡异的是：这段完全相同的代码在旧版 Android 10、11 或老款模拟器上运行得非常顺畅，一旦来到最新的 Android 16 真机，只要手指轻触输入框或弹出软键盘，App 就**立刻发生致命闪退**！

本篇将深入 AOSP 原生源码，剖析这一高版本特有 Bug 的底层成因，并提供一套能够**完美通杀 Android 7.0 到 Android 16 全版本的安全构建方案**。

---

## 一、 AOSP 源码溯源：崩溃为什么会发生？

### 1. Unity 原生主题的“先天缺陷”
在 `AndroidManifest.xml` 中，游戏主入口 `UnityPlayerActivity` 通常配置了全屏无标题栏主题：

```xml
android:theme="@android:style/Theme.NoTitleBar.Fullscreen"
```

这种主题专为纯 OpenGL / Vulkan 全屏渲染设计，其底层风格属性表中**根本没有为标准的 Android 原生 UI 控件配置任何滚动条样式（Scrollbar Style）和颜色资源**。

### 2. AOSP 内部状态不一致
翻开 Android 开源项目（AOSP）中 `View.java` 的实现源码：

```java
// AOSP View.java (精简关键路径)
protected void onDrawScrollBars(Canvas canvas) {
    final ScrollBarCache cache = mScrollBarCache;
    if (cache == null) {
        return;
    }

    final ScrollBarDrawable scrollBar = cache.scrollBar;
    // 💥 致命崩溃点：
    // 在 Android 15+ 中，Google 优化了滚动条绘制，假定只要开启了滚动条，scrollBar 就必然非空！
    scrollBar.mutate(); // 如果没有通过标准 Theme 赋初值，此处抛出 NullPointerException!
}
```

当我们使用代码动态创建 `EditText` 并顺手调用了诸如 `setScrollbarFadingEnabled(false)` 或 `setVerticalScrollBarEnabled(true)` 时，系统创建了 `cache` 对象，但由于父级 Unity 宿主缺少 Dialog 主题，`cache.scrollBar` **始终为 null**！

当下一次硬件加速渲染管线（`draw()`）尝试绘制这个输入框时，空指针解引用瞬间引爆应用崩溃。

## 二、 修复方案：双保险防御体系

要彻底根治这一深水区崩溃，必须同时采用**“主题上下文包装”**与**“安全滚动条防护”**双重保险。

### 保险一：使用 `ContextThemeWrapper` 注入独立主题上下文
绝对不要直接使用原生的 `activity` 作为 `EditText` 或 `AlertDialog` 的上下文！必须使用 `ContextThemeWrapper` 将其包裹为一个拥有完整 Material / Dialog 属性的独立上下文：

```javascript
// context_theme_wrapper_helper.js

function getThemedContext(activity) {
    const ContextThemeWrapper = Java.use("android.view.ContextThemeWrapper");
    
    // 使用 Android 系统内置的标准设备默认对话框主题 (Theme.DeviceDefault.Light.Dialog)
    // 资源 ID: 0x01030224
    const THEME_DEVICE_DEFAULT_DIALOG = 0x01030224;
    
    return ContextThemeWrapper.$new(activity, THEME_DEVICE_DEFAULT_DIALOG);
}
```

通过这一层包裹，控件内部的所有属性（包括滚动条、高光、光标、涟漪动画）全部从标准的 Dialog 样式继承，消除了主题资源缺失的隐患。

### 保险二：显式禁用不稳定滚动条属性
对于普通单行或几行文本的卡组代码输入框，完全不需要复杂的系统原生滚动条。在动态构建 `EditText` 时，**显式关闭物理滚动条绘制**：

```javascript
// safe_edittext_factory.js

function createSafeInput(themedContext) {
    const EditText = Java.use("android.widget.EditText");
    const input = EditText.$new(themedContext);

    // 1. 显式关闭垂直滚动条，避免进入 onDrawScrollBars 的危险分支
    input.setVerticalScrollBarEnabled(false);
    input.setHorizontalScrollBarEnabled(false);

    // 2. 严禁调用 setScrollbarFadingEnabled(false)！
    // 该方法在高版本没有配置 Drawable 时会强制唤醒未初始化的 Cache！

    // 3. 设置内部输入滚动安全边界
    input.setMaxLines(6);
    input.setSingleLine(false);
    
    return input;
}
```

## 三、 完整安全对话框实战重构代码

将上述两项防御机制融合进真实的业务弹窗中：

```javascript
// production_safe_dialog.js

function showBulletproofDialog(activity, onImportText) {
    Java.perform(() => {
        const AlertDialog = Java.use("android.app.AlertDialog$Builder");
        const ContextThemeWrapper = Java.use("android.view.ContextThemeWrapper");
        const EditText = Java.use("android.widget.EditText");
        const LinearLayout = Java.use("android.widget.LinearLayout");

        // 1. 获取具备完备属性的主题上下文
        const themedCtx = ContextThemeWrapper.$new(activity, 0x01030224);

        // 2. 构建安全的容器布局与输入框
        const layout = LinearLayout.$new(themedCtx);
        layout.setOrientation(1); // VERTICAL
        layout.setPadding(40, 20, 40, 20);

        const input = EditText.$new(themedCtx);
        input.setHint("在此粘贴卡组分享码 (支持 PVZH1: 或 Base64)");
        input.setVerticalScrollBarEnabled(false); // 关键避坑: 规避 AOSP NPE
        layout.addView(input);

        // 3. 构建弹窗实例
        const builder = AlertDialog.$new(themedCtx);
        builder.setTitle("分享码安全导入");
        builder.setView(layout);

        builder.setPositiveButton("确定", Java.registerClass({
            name: "com.pvzh.mod.SafeConfirmListener",
            implements: [Java.use("android.content.DialogInterface$OnClickListener")],
            methods: {
                onClick: function (dialog, which) {
                    const text = input.getText().toString().trim();
                    dialog.dismiss(); // 异步排队关闭
                    if (text) onImportText(text);
                }
            }
        }).$new());

        builder.setNegativeButton("取消", null);

        builder.create().show();
        console.log("✅ 全版本自适应安全弹窗已顺利弹出，无惧 Android 16 NPE！");
    });
}
```

## 四、 本篇总结与经验沉淀

| 故障现象 | 触发环境 | 根本原因 | 根治对策 |
| :--- | :--- | :--- | :--- |
| `ScrollBarDrawable.mutate()` 报 NPE | Android 15 / 16 (API 35~36) 高版本真机 | Unity 全屏主题缺失标准 Dialog 滚动条资源，AOSP 绘制层未判空直接调用 | 1. 使用 `ContextThemeWrapper` 注入独立主题；<br/>2. 显式禁用不稳定滚动条 `setVerticalScrollBarEnabled(false)`。 |
