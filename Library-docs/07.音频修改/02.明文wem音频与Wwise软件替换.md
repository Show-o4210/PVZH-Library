# 02. 明文 WEM 音频与 Wwise 软件替换

本篇用于把**自制音频**转换成游戏可读取的 WEM，替换 `streaming_audio/` 中的独立文件。仅提取/试听原音乐请看[第 06 篇](06.wwiser与vgmstream音乐编排导出.md)，无需安装 Wwise Authoring。

## 一、准备工作与版本选择

原教程推荐 Wwise **2019.2.15.7667**，可作为沿用原流程时的候选版本，但本次 BGM 提取未重新测试其转码兼容性。

不能把它称作唯一兼容版本，也不能断言所有更旧版本都没有 CLI。Wwise 的早期文档已有命令行相关内容；不同年代的入口可能是 `WwiseCLI.exe` 或 `WwiseConsole`，按对应版本说明使用。参见 [Audiokinetic 2015.1.9 用户手册](https://www.audiokinetic.com/files/?get=2015.1.9_5624%2FWwise_UserGuide_en.pdf)与[现代 WwiseConsole 示例](https://www.audiokinetic.com/library/2024.1.2_8726/?id=wwise_console_example_index.html&source=SDK)。

选择工具时需要匹配游戏运行时可读取的**编码、媒体格式和目标平台**。能够生成 `.wem` 不等于游戏一定能播放。银行的版本号也不应直接当作 Authoring 的完整版本号。

准备事项：

1. 备份目标 WEM，并记录名称、大小、哈希、采样率、声道和时长。
2. 准备自制 WAV；尽量匹配原资源的采样率/声道。提高采样率不会恢复源文件没有的音质。
3. 先替换一个已确认用途的文件验证，不批量覆盖全部数字 ID。

## 二、Wwise 转码四步法

### 1. 导入音频

新建工程，在 `Actor-Mixer Hierarchy` 中使用 `Import Audio Files` 导入自制 WAV。

### 2. 设置转换参数

在音频属性的 `Conversion Settings` 中配置编码和采样率。本次音乐资源为 Vorbis，可从 Vorbis 开始试验；原教程的 Quality 4/5 仅是体积与质量的起点，不是兼容性保证。

使用与设备相符的 **Android 目标平台**，同时核对转换设置是否在该平台被覆盖。不要无条件使用 Windows 的缓存输出替换 Android 文件。

### 3. 转换并定位输出

选中音频，执行 `Convert Audio Files`。在当前版本的转换日志及工程缓存目录中定位目标 `.wem`；具体目录随平台、语言与工程配置变化，不固定为 `.cache/Voices/Windows/SoundBanks/`。

### 4. 同名替换并验证

将生成文件重命名为目标 ID，例如 `123456789.wem`，仅替换副本后再部署到：

```text
/storage/emulated/0/Android/data/com.ea.gp.pvzheroes/files/streaming_audio/123456789.wem
```

检查是否实际打开目标文件、能否正常播放、循环/转场是否正常。缓存刷新或资源同步可能覆盖修改，不能仅以成功复制判断成功。

## 三、替换背景音乐的额外限制

同名替换不会自动改变 SoundBank 中的 segment 时长、entry/exit cue、裁剪和循环规则。将一首长歌塞进一个短片段 ID，可能只播放其中一部分、出现空隙或不正常的转场。

优先匹配原片段的时长与结构。需要修改编排或内嵌媒体时，进入[第 03 篇](03.AB包内BKHD SoundBank解构与手改警告.md)和[第 04 篇](04.QuickBMS与社区工具自动化替换.md)的银行流程；不要把独立 WEM 替换与银行重建混为一谈。
