# 00. 游戏介绍

本章节主要介绍《植物大战僵尸：英雄》（PVZH）的游戏引擎版本、核心资源包存放目录以及 Mod 制作过程中的入门注意事项。

---

## 一、 游戏引擎信息

- **引擎版本**：**Unity 2022.3.68f1**
- **技术要点**：
  - 了解 Unity 引擎版本对于解包与修改至关重要。在后续使用 AssetBundle 修改工具（如 UABEA 等）时，需确保工具支持或兼容 Unity 2022.x 系列的版本格式，以免出现资源包无法解析或保存报错的情况。

---

## 二、 核心资源包与目录结构

PVZH 的主要游戏资源与配置文件采用动态下载/缓存的 AssetBundle 机制存放于本地。在 Android 设备（或模拟器）中，核心资源包根目录为：

```text
/storage/emulated/0/Android/data/com.ea.gp.pvzheroes/
```

其下包含几个最核心的 Mod 修改目录：

| 资源类别 | 对应路径 | 说明与修改重点 |
| :--- | :--- | :--- |
| **卡牌数据** | `.../files/cache/bundles/files/cards/` | **改版核心重点**。包含卡牌属性、数值、费用、技能与效果等数据资源。 |
| **本地化文本** | `.../files/cache/bundles/files/loc/` | 游戏多语言文本包（包括卡牌名称、技能描述、UI 提示文本等）。 |
| **贴图素材** | `.../files/cache/bundles/files/autotagged/` | 游戏中的各类贴图、精灵图（Sprite）、纹理资源。 |
| **关卡数据** | `.../files/cache/bundles/files/data_assets_40` | 包含单人关卡、关卡配置与关卡节点相关数据。 |

> [!NOTE]
> 完整相对路径前缀通常为：
> `/storage/emulated/0/Android/data/com.ea.gp.pvzheroes/files/cache/bundles/files/`

## 三、 Mod 制作入门注意事项与避坑指南

对于刚接触 PVZH Mod 修改的开发者，以下是常见的异常现象及其对应原因排查：

### 1. 游戏卡在加载界面（无法进入主界面）
- **主要原因**：大概率是 `cards` 目录下的卡牌数据（如 `card_data` 等）改动存在逻辑冲突、非法数值或关联引用损坏。
- **排查建议**：优先检查最近修改过的卡牌数值与字段属性，还原单项修改进行对比排查。

### 2. 游戏直接闪退（Crash）
- **主要原因**：大概率是**格式语法错误**。
  - 混入了**中文标点符号**（如中文逗号 `,`、中文双引号 `“”`、中文冒号 `:` 等）。
  - 括号未匹配或缺失（如 JSON / 配置文件的 `{}`、`[]` 闭合错误）。
- **排查建议**：在保存修改前，使用代码/文本编辑器（如 VS Code、Notepad++ 等）严格检查语法与字符编码，确保所有标点均为英文字符。
