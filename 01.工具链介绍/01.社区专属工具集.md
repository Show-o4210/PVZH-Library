# 01. 社区专属工具集（休切尔工具链）

为降低 PVZH Mod 制作的门槛、避免繁琐且易出错的手工修改，社区开发者 **休切尔 (Show-o4210)** 针对 PVZH 的数据结构与开发需求，开源了一系列可视化辅助工具、编辑器与配套工具集。

- **开发者 GitHub 主页**：[https://github.com/Show-o4210](https://github.com/Show-o4210)
- **开源协议**：全系工具免费公开开源（MIT / GPL License）

---

## 一、 PVZH 核心开源工具集

### 1. PVZH-Card-Editor (卡牌 Mod 编辑器)
- **仓库地址**：[Show-o4210/PVZH-Card-Editor](https://github.com/Show-o4210/PVZH-Card-Editor)
- **主要功能**：专门用于修改与制作 PVZH 卡牌 Mod 的可视化编辑器，简化卡牌数值、效果与配置字段的编辑流程。

### 2. PVZH-Level-Editor (关卡 Mod 编辑器)
- **仓库地址**：[Show-o4210/PVZH-Level-Editor](https://github.com/Show-o4210/PVZH-Level-Editor)
- **主要功能**：PVZH 关卡数据（对应 `data_assets_40`）图形化编辑工具。提供直观界面调整关卡出怪、对局配置与节点参数，并支持语法自动校验，避免游戏闪退。

### 3. pvzh-local-inventory-mod (本地卡牌解锁 Mod)
- **仓库地址**：[Show-o4210/pvzh-local-inventory-mod](https://github.com/Show-o4210/pvzh-local-inventory-mod)
- **主要功能**：支持让 PVZH 游戏通过读取本地 JSON 配置文件，获取正常对局中无法/难以获得的卡牌，方便 Mod 测试与卡牌调优。

---

## 二、 逆向与环境辅助工具

### 1. il2cpp-string-loc-toolkit (IL2CPP 文本汉化/修改工具)
- **仓库地址**：[Show-o4210/il2cpp-string-loc-toolkit](https://github.com/Show-o4210/il2cpp-string-loc-toolkit)
- **主要功能**：针对 Unity IL2CPP 游戏的通用字符串/多语言提取与修改工具，主要用于处理存放于 `global-metadata.dat` 中的硬编码文本。

### 2. emu-ad-cleaner (开发模拟器去广告指南)
- **仓库地址**：[Show-o4210/emu-ad-cleaner](https://github.com/Show-o4210/emu-ad-cleaner)
- **主要功能**：记录了安卓模拟器（如雷电9、MuMu 12）去除广告、提升开发调试纯净度与稳定性的操作教程。

---

## 三、 工具运行环境搭建

上述开源工具多数基于 Python 构建，并配备 GUI 图形化界面（PySide6）与底层资源解析库（UnityPy）。

### 1. 一键安装基础依赖
确保系统已安装 **Python 3.9+**，在终端运行：

```bash
pip install PySide6 UnityPy
```

### 2. 依赖库作用说明
- **`PySide6`**：提供图形用户界面，免去命令行操作。
- **`UnityPy`**：底层 AssetBundle 自动化解析引擎，实现资源的读取、修改与保存。
