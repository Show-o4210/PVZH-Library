# 原版自然语言制卡核心

- 本工具是原版数据编译器，不引入Gadget、私有Grant编号、设备操作或自动安装。
- 模型只生成plan，不能生成可执行代码或绕过core.py验证。未知需求返回clarify/unsupported；未开放不等于原版永远不可能。
- 原始Bundle只读，输出目录不覆盖；每次单卡构建是独立项目，累计修改由项目层合并patch。
- 新原包须调查后登记canonical指纹，不删版本守卫。查询、字段、枚举从匹配原包提取，不凭旧教程猜测。
- API密钥仅交给进程内provider，不放进示例、模型上下文、日志或报告。
- 样例、文档与评测分清JSON理解、结构、回包、游戏结算、动画五层。工具内测试只做离线／API验证；后续六份方案的独立设备抽测见第22章04，不改旧静态报告，也不扩大为所有配方已验证。
