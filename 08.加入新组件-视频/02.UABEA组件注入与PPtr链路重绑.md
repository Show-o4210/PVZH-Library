# 02. UABEA 组件注入与 PPtr 链路重绑

获得 `VideoPlayer` 的 Dump 模板后，即可通过 UABEA 向原版卡牌 AssetBundle 中注入该组件，并重新缝合指针链路。

本篇结合资源目录中的实操修补包 **[2ceeb890a69397041ba1fd559056c358_1_patched](../资源/2ceeb890a69397041ba1fd559056c358_1_patched)**（鳄梨鳄卡牌修补包）的真实解析数据进行拆解讲解。

## 二、 UABEA 四步注入与重绑流程

### 第一步：在目标卡牌包中创建 Class 328 (VideoPlayer)

1. 用 UABEA 打开干净的原版卡牌 AssetBundle。
2. 点击 **`Info`** 进入资源列表。
3. 点击上方菜单 **`Assets` -> `Create Asset`**：
   - 输入 Class ID **`328`** (VideoPlayer)。
   - 为新建的对象指定一个专用的 PathID（例如 **`999999`**）。
4. 选中新建的 `VideoPlayer` (999999)，右键选择 **`Import Dump`**，载入上一篇生成的 `VideoPlayer_dump.txt`。

---

### 第二步：绑定挂载实体 (m_GameObject)

1. 在列表中找到卡牌的主身体 `GameObject`，记录其 PathID（如鳄梨鳄身体的 `2505563530246109078`）。
2. 选中新建的 `VideoPlayer` (`999999`)，点击右侧 **`Edit Data`**。
3. 将 `m_GameObject` 字段修改为：
   ```yaml
   m_GameObject: {fileID: 0, pathID: 2505563530246109078}
   ```

---

### 第三步：重定向渲染器 (m_TargetMaterialRenderer)

1. 在列表中找到卡牌身体的 `SpriteRenderer` 组件，记录其 PathID（如 `-824107450763009214`）。
2. 打开 `VideoPlayer` (`999999`) 的 Edit Data：
   - 将 `m_TargetMaterialRenderer` 指向该 `SpriteRenderer`：
     ```yaml
     m_TargetMaterialRenderer: {fileID: 0, pathID: -824107450763009214}
     ```
   - 确认 `m_TargetMaterialProperty` 属性字符串为 **`_MainTex`**。

---

### 第四步：反向挂载与 URL 配置

1. **反向挂载组件**：
   导出卡牌身体 `GameObject` (`2505563530246109078`) 的 Dump 文本。展开 `m_Component` 数组，将 `size` 增加 `1`，并在末尾追加指向 `999999` (`VideoPlayer`) 的条目。
2. **确认 MP4 URL 路径**：
   在 `VideoPlayer` 数据中确认 `m_Url` 为对应的安卓真机存储路径：
   `file:///storage/emulated/0/Android/data/com.ea.gp.pvzheroes/files/cache/bundles/files/video/card_video.mp4`

完成上述步骤后，保存 Bundle。只要在手机对应路径下放置 MP4 视频文件，启动游戏后，卡牌画面就会自动播报动态视频！
