# 03. 富文本与图标标记语法

在 PVZH 的本地化文本（如 [cn.csv](../cn.csv)）中，很多卡牌技能描述中包含了形如 `[+1a]`、`[frenzy]`、`\n` 等特殊标签。游戏引擎在渲染卡牌面板时，会自动解析这些标签并将其替换为对应的攻击力图标、生命值图标、关键字小图标及富文本格式。

---

## 一、 属性与增益数值图标标记

在技能描述中，任何有关攻防增减的文字均使用专用中括号标记：

| 标记语法 | 渲染效果说明 | CSV 真实文本示例 |
| :--- | :--- | :--- |
| **`[+Xa]`** | 渲染为 **+X 攻击力**（带有攻击图标） | `一株植物获得[+1a]/[+1h]。` |
| **`[+Xh]`** | 渲染为 **+X 生命值**（带有生命图标） | `使一个僵尸获得[+2h]。` |
| **`[-Xa]`** | 渲染为 **-X 攻击力**（带负向攻击图标） | `使一株植物获得[-2a]。` |
| **`[-Xh]`** | 渲染为 **-X 生命值**（带负向生命图标） | `使一个随从获得[-3h]。` |

---

## 二、 关键字图标标记 (Keyword Icons)

使用中括号包裹关键字英文原名，游戏引擎会自动渲染出对应的 UI 图标：

| 图标标记 | 对应关键字 | 渲染效果 | CSV 真实示例 |
| :--- | :--- | :--- | :--- |
| **`[frenzy]`** | 狂暴 (Frenzy) | 狂暴关键字图标 | `[frenzy]\n在消灭植物时获得[+2a]/[+2h]。` |
| **`[armor1]` / `[armor]`** | 护甲 (Armor) | 护甲盾牌图标 | `[armor1]。当此植物受到伤害时...` |
| **`[strikethrough]`** | 贯穿 (Strikethrough) | 贯穿图标 | `[strikethrough]\n登场：抽一张牌。` |
| **`[untrickable]`** | 无法成为法术目标 | 免疫法术图标 | `[untrickable]` |
| **`[bullseye]`** | 无视盾牌 (Bullseye) | 靶心精准图标 | `[bullseye]` |
| **`[amphibious]`** | 水生 (Amphibious) | 波浪水生图标 | `[amphibious]` |
| **`[teamup]`** | 团队协作 (Team-Up) | 协作图标 | `[teamup]` |
| **`[overshoot2]`** | 先发制人 2 (Overshoot) | 先攻图标 | `[overshoot2]` |

---

## 三、 换行符与格式化语法

1. **显式换行符 (`\n`)**：
   在 CSV 中换行不能直接按下 Enter 键换行（否则会导致 CSV 行结构损坏），必须使用转义字符 **`\n`**。
   - 正确写法：`[frenzy]\n在消灭植物时获得[+2a]/[+2h]。`
2. **Unity 富文本颜色 (Rich Text)**：
   支持标准的 Unity TextMeshPro 标签：
   - `<color=#FF0000>高亮红字</color>`
   - `<b>加粗文本</b>`
3. **动态变量插值 (`{0}`, `{1}`)**：
   在系统提示或部分动态关卡文本中，`{0}`、`{1}` 会在游戏运行时被 C# 代码替换为实际的数值或卡牌名称。

---

## 四、 修改与撰写建议

> [!TIP]
> 1. 在为新卡牌撰写中文技能描述时，**务必优先使用 `[+1a]`、`[+1h]` 代替纯文字的“+1攻击”**，这样渲染出来的卡牌面板在视觉上才符合 PVZH 官方的原汁原味规范。
> 2. 避免在 CSV 的 Value 文本中随意使用未闭合的尖括号 `<` 或未转义的英文双引号 `"`，以免打破 CSV 解析器的读取界限。
