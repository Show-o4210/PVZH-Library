# 01. 文件结构与 UABEA 导出

在《植物大战僵尸：英雄》（PVZH）中，大量界面文本、卡牌名称、技能描述及故事风味与底层卡牌数据解耦，保存在 `loc/` 多语言资源包中。并非屏幕上的全部文字都必然来自这份语言包；动态注入文字另见[批量翻译工作流](04.复用引用与批量翻译工作流.md)。

---

## 一、 语言包存放路径

在安卓设备或模拟器中，多语言资源包存放在缓存 Bundles 路径下：

```text
/storage/emulated/0/Android/data/com.ea.gp.pvzheroes/files/cache/bundles/files/loc/
```

在该目录下包含不同语种的语言包文件（无文件后缀或后缀为 `.bundle`）：

APK 内也可能自带 `assets/AssetBundles/loc/cn`。设备实际读取内置包还是缓存包，应结合当前底座与资源门卫配置确认，不能只凭某个目录中存在同名文件判断已经生效。

| 文件名 | 所属语言 | 对应的解包文本 |
| :--- | :--- | :--- |
| **`cn`** | 简体中文 (Simplified Chinese) | `cn.csv`（如资源目录 [cn.csv](../资源/cn.csv)） |
| **`en`** | 英文 (English) | `en.csv` |
| **`zh_tw` / `tw`** | 繁体中文 (Traditional Chinese) | `zh_tw.csv` |
| **`jp` / `de` / `fr`** | 日语 / 德语 / 法语 | 对应语种文本 |

---

## 二、 使用 UABEA 导出 CSV 文本 (以 cn 包为例)

要把 `loc/cn` 语言包解包为像资源目录 [cn.csv](../资源/cn.csv) 一样的可编辑文本文件，请遵循以下简单步骤：

1. **打开文件**：
   - 打开 UABEA (`UABEAvalonia.exe`)，点击 `File` -> `Open`，选择 `files/loc/cn` 文件。
   - 弹出的解压提示框中选择 **`Memory`**。
2. **进入 Info 视图**：
   - 选中列表中的 Asset 条目，点击右侧的 **`Info`** 按钮。
3. **定位 TextAsset 节点**：
   - 在 Asset Info 视窗中，找到 `Type` 为 **`TextAsset`** 的资源条目，读取其 `m_Name` 并核对 `m_Script`。已核对案例的名称为 **`LocalizedStrings`**，不是外部文件名 `cn`。
4. **导出文本内容**：
   - 使用当前工具提供的 TextAsset 文本导出功能，取得 `m_Script` 的 CSV 内容，再保存为 `cn.csv`。
   - **序列化 Dump 不等于 CSV**。如果使用 `Export Dump` 得到含 `m_Name`、`m_Script` 等字段的结构文本，应保留该结构，并与同类 Dump 导入配对；不要只改扩展名就把它当纯 CSV。

---

## 三、 CSV 格式规范与编码注意点

导出的 `cn.csv` 文件具有以下格式特点：

1. **分隔符**：标准逗号分隔值格式（`Key,Value`）。
2. **字符编码**：保持原始 **UTF-8** 表示，不另存为 ANSI 或 GBK。**原表有 BOM 就保留，没有就不新增**。2026-10-16 的 B4 输入首键确含 BOM 与特殊前缀，不能套用“一律去 BOM”的规则；检索时可生成逻辑键，回写仍保留原字段。
3. **推荐编辑器**：强烈推荐使用 **VS Code**、**Sublime Text** 或 **Antigravity IDE** 进行修改。
4. **记录边界**：CSV 中引号包裹的多行字段有效；不要按物理行拆记录、用 `split(',')` 拆列或删除空键填充。原字段中的字面反斜杠换行与物理换行分别保留，详见[标记语法](03.富文本与图标标记语法.md)。

---

## 四、 重新导入与重新打包流程

完成文本修改后，按以下步骤重新打入 Bundle 包：

1. 打开 UABEA，再次 `Open` 打开原版的 `loc/cn` 文件并点击 `Info`。
2. 选中相同 TextAsset，使用与导出格式匹配的导入方式。
3. 纯 CSV 应写回该 TextAsset 的 `m_Script`；序列化 Dump 才交给 `Import Dump`。不同 UABEA 版本的文本插件与按钮名称可能不同，导入后必须检查字段内容；不能把裸 CSV 当 Dump 直接导入。
4. **保存 Info**：在 `Info` 视窗菜单栏点击 **`File` -> `Save`**（然后关闭 Info 视窗）。
5. **保存 Bundle**：在 UABEA 主界面菜单栏点击 **`File` -> `Save`**，另存为新的 `cn` 文件。
6. 回读新 Bundle，确认 CSV 内容与目标文字一致、只有预期 TextAsset 改变。备份设备目标文件后，使用 **MT管理器** 或既有部署流程将新包放到实际生效的位置，重启并检查文字。仅复制成功不足以证明当前游戏已加载它。

UnityPy 的已核对读写方式见 [Agent Bundle 指南](../agents/01-bundles-and-scope.md)；完整翻译的验证层次见[复用引用与批量翻译工作流](04.复用引用与批量翻译工作流.md)。
