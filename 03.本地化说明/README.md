## 核心要点概览

1. **资源存放路径**：
   多语言资源存放于设备路径：
   `/storage/emulated/0/Android/data/com.ea.gp.pvzheroes/files/cache/bundles/files/loc/`
   其中 `cn` 为简体中文语言包，`en` 为英文语言包。
2. **Key-Value 组织形式**：
   解包 TextAsset 的 `m_Script` 为 CSV（历史参考见 [cn.csv](../资源/cn.csv)）。记录包含键名与文字，可能还有额外列、空键填充和引号内物理换行；编辑时保留原始结构与 BOM 状态。
3. **卡牌与 UI 双重解耦**：
   卡牌数值与逻辑存放在卡牌数据包中；中文名称、说明和故事通常以 `prefabName + 后缀` 从语言包取值。`prefabName` 可呈 GUID 外观，但不要与数字卡牌编号混用。
4. **复用内容不只在 cn 内部**：
   标记可经 `fonts/inline_text_tag` 引用 cn 的共享名。翻译值不改键、标记和参数；新增一行 `temp,文字` 不足以证明 `[temp]` 已可使用。

只做少量增量修改可结合 [Agent 中文指南](../agents/03-levels-and-localization.md)；全量翻译先读 04，再按 05 的边界记录交付。历史资源表是参考，不替代用户当前输入。
