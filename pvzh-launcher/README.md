# PVZH 启动器

PVZH 启动器是《植物大战僵尸：英雄》的第三方 Android Mod 工作台。它提供 Mod 管理、卡牌和美术编辑，以及游戏资源准备等入口。手机操作和版本能力见[启动器工作台指南](../Library-docs/24.启动器工作台与手机编辑/README.md)。

这里公开项目简介和启动器语言表。完整客户端与 Hook 实现由独立工程维护。

## 启动器本地化

[简体中文语言表](i18n/zh-CN/)来自 **r-2-29 RC2** 开发候选，基于 r-2-28 RC1，包含 5,186 条启动器界面文案。六个 JSON 文件按用途组织，包括导航、设置、编辑器、AI 工作台、资源进度与错误提示。这是第一阶段，候选仍显示简体中文。

欢迎通过 Issue 反馈文案问题，或用 Pull Request 提交翻译建议。请保留 JSON 键以及 `{0}`、`{1}` 等占位符，按目标语言调整它们的位置。游戏本体与 Mod 自带文本各自使用自己的资源。许可范围见[许可证索引](../LICENSES.md)。

## About the launcher

PVZH Launcher is a third-party Android Mod workbench for *Plants vs. Zombies Heroes*. This folder publishes the project overview and the [Simplified Chinese UI catalog](i18n/zh-CN/) from development build **r-2-29 RC2**. English UI support is a future phase. Translation feedback is welcome via Issues or Pull Requests. Keep the JSON keys and numbered placeholders such as `{0}` when proposing translations.
