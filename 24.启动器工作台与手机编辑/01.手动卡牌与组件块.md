# 手机手动卡牌与组件块

适用范围为 Android R48 RC2。R44曾有紧凑／原始编辑和分开的保存入口；R45已经移除这些玩家入口，R48继续沿用简化后的操作。

## 玩家操作

选择或新建Mod，搜索并打开卡牌后，主操作只有 **基础、词条、积木、保存** 四项。顶部统一放返回、撤销和重做图标。基础页可改费用、攻血、名称与说明、阵营等；词条使用开关和必要数值。展示种族、标签和属性图标按单项添加／修改／移除，无需输入JSON。展示图标本身不等于获得相应原生技能。

技能通过新增技能组、空组或模板开始。组件库提供常见组合，原子库保留细化表达路径；长按组或积木展开临时操作，并可在同一列表中拖动排序。保存统一写入当前Mod，成功后留在当前页，玩家无需区分内部工程与Mod写回。

任意原始JSON、复杂特殊列表和工程导入导出不再面向玩家。无法识别的旧内容保留，特殊字段交维护者处理；打开、查看和取消不会据默认值重建整张卡。

## 14类组件

组件把一棵常用原生子树作为一个易理解的块显示；保存仍是原生 `$type`／`$data`，不新增游戏类型或组件包装。组件与原子积木遵循同样的插槽类别约束。

| 家族ID | 名称 | 变体与职责 |
|---|---|---|
| `hero_target` | 英雄目标 | 植物／僵尸英雄，作为效果目标 |
| `unit_target` | 单位目标 | 阵营、全部／手动／随机、数量及叠加筛选 |
| `self_target` | 自身目标 | 当前实体作为效果目标 |
| `hero_query` | 英雄范围 | 查询植物／僵尸英雄 |
| `unit_query` | 单位范围 | 查询场上单位，可叠加筛选，不附带选取数量 |
| `terrain` | 基础地形 | 平地／水路／高地 |
| `environment` | 环境状态 | 有环境／无环境 |
| `lane` | 位置关系 | 自身、事件来源、事件目标同路；自身两侧／左／右邻路 |
| `self_event` | 事件对象为自身 | 将触发事件对象限定为当前实体 |
| `self_alive` | 自身存活且允许触发 | 组合存活与触发许可条件 |
| `self_event_alive` | 自身事件保护 | 自身事件、存活及允许触发 |
| `self_event_death` | 自身离场效果许可 | 自身事件与离场效果许可 |
| `exclude_self` | 排除自身 | 与其他候选范围组合使用 |
| `tribe_pool` | 指定种族牌池 | 数字种族，并排除超能力；它本身不负责抽取或获取卡牌 |

单位目标／范围可叠加阵营、相对线路、地形、环境、排除自身和数字种族条件。基础地形与环境是两组条件，可以同时存在。种族编号0是实际编号，不用作“不限”；是否限定种族由独立开关决定。

植物／僵尸是明确阵营，暂没有自动随持有者改变的“己方／敌方”组件快捷项。英雄目标不自带伤害或治疗，事件保护也不自动添加打出／回合开始触发器。数值类型检查不证明场上有足够目标或玩法平衡。

## R48手机友好化

- 常用编辑器按钮至少52dp，顶部图标48dp，开关56dp；输入17sp、积木参数16sp，共享小字最低14sp，并遵循系统字体缩放。
- 主选项卡、组件／原子库和类别有明确选中状态；按压、输入聚焦、长按选中及拖动落点提供反馈。
- 固定位置栏随分区、当前可见积木与内部层级变化；基础／词条／积木保留本卡会话内的滚动位置。
- 组件内部默认展开，可手动收起；重新打开卡牌恢复默认展开。参数分为输入数值／文字、选项选择和开关，较窄参数行上下排列。

显示预算保持180节点、10层深度、每列表40项，并保留逐层进入。超过预算不代表内容消失，也不把显示预算当成卡牌保存截断。组件识别要求完整受管配方；额外字段或未知关系会退出组件识别，不能强行改写。修改前继续核对节点指纹，过期路径拒绝写入；更换家族属于明确的整棵子树替换。

## 已验证与未验证

R44本机组件模型覆盖14家族和原版识别、参数往返、未知字段回退等；原内核受控场景曾完成一次合法出牌，敌方英雄生命50→47。它不是全部组件变体或完整正式胜负验收。

R48当前108源的1567项独立模型／保存回归与4次Bundle读取通过；正常UI检查输入、切页、参数分区、开关、长按拖动撤销、保存和冷启重开。实际保存样本独立读取时，650张原卡和10783旧中文键保持。逐键／逐记录循环不能宣传为同数量的功能测试。

手机普通显示及320dp宽＋1.3倍字体已经实测；横屏、任意输入法／手机、全部原生节点和正式对局未在R48重新穷举。
