# 07. 检测与判定逻辑 JSON 复制模板 (Queries & Filters)

在 PVZH 的 `EffectEntitiesDescriptor` 技能逻辑中，**检测与判定逻辑 (Queries & Filters)** 节点用于进行条件检查与过滤，只有当目标条件断言计算结果为真（True）时，后面的技能效果（Effects）才会触发执行。

本篇提供纯净、可直接复制到 JSON 编辑器中（**无内嵌注释，避免语法报错**）的检测与判定代码块。

---

## 一、 复合逻辑门 (Composite Queries)

复合逻辑门用于将多个基础判定条件组合在一起，形成“与”（All）或“或”（Any）的条件树。

### 1. 复合与门：必须同时满足以下全部条件 (`CompositeAllQuery`)

只有当 `queries` 数组中的所有子条件同时为 True 时，整体判定才通过。

```json
{
  "$type": "PvZCards.Engine.Queries.CompositeAllQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "queries": [
      {
        "$type": "PvZCards.Engine.Queries.WillTriggerEffectsQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
        "$data": {}
      },
      {
        "$type": "PvZCards.Engine.Queries.IsAliveQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
        "$data": {}
      }
    ]
  }
}
```

#### 参数详解：
- **`queries`** (数组): 包含多个独立 Query 条件对象的数组。

---

### 2. 复合或门：满足以下任一条件即可 (`CompositeAnyQuery`)

只要 `queries` 数组中有一个子条件计算为 True，整体判定即通过。

```json
{
  "$type": "PvZCards.Engine.Queries.CompositeAnyQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "queries": [
      {
        "$type": "PvZCards.Engine.Queries.FighterQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
        "$data": {}
      }
    ]
  }
}
```

---

### 3. 非门取反：不满足目标条件时 (`NotQuery`)

对内部传入的 Query 条件计算结果取反（True 变 False，False 变 True）。

```json
{
  "$type": "PvZCards.Engine.Queries.NotQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "Query": {
      "$type": "PvZCards.Engine.Queries.IsAliveQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
      "$data": {}
    }
  }
}
```

---

## 二、 实体与触发器过滤器 (Filters)

用于在特定事件发生时，约束“是谁触发了事件”或“事件对谁造成了影响”。

### 1. 实体自身过滤器 (`SelfEntityFilter`)

限制仅当事件的目标对象为随从/卡牌**自身**时，才允许执行后续逻辑。

```json
{
  "$type": "PvZCards.Engine.Components.SelfEntityFilter, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "Query": {
      "$type": "PvZCards.Engine.Queries.CompositeAllQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
      "$data": {
        "queries": [
          {
            "$type": "PvZCards.Engine.Queries.IsAliveQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
            "$data": {}
          }
        ]
      }
    }
  }
}
```

---

### 2. 触发目标过滤器 (`TriggerTargetFilter`)

用于在受伤害、被攻击等事件中，判定“遭受事件打击的目标对象”是否符合条件。

```json
{
  "$type": "PvZCards.Engine.Components.TriggerTargetFilter, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "Query": {
      "$type": "PvZCards.Engine.Queries.IsAliveQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
      "$data": {}
    }
  }
}
```

---

### 3. 触发源过滤器 (`TriggerSourceFilter`)

用于判定“发起/造成该事件的来源者”是否符合条件（例如：“当僵尸造成伤害时”）。

```json
{
  "$type": "PvZCards.Engine.Components.TriggerSourceFilter, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "Query": {
      "$type": "PvZCards.Engine.Queries.FighterQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
      "$data": {}
    }
  }
}
```

## 三、 常用状态断言查询 (Queries)

### 1. 实体存活断言 (`IsAliveQuery`)

检查目标随从/实体当前生命值是否大于 0，且未处于销毁状态。

```json
{
  "$type": "PvZCards.Engine.Queries.IsAliveQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

### 2. 随从/战斗者断言 (`FighterQuery`)

检查目标实体是否为处于战场上的随从实体（植物随从或僵尸随从）。

```json
{
  "$type": "PvZCards.Engine.Queries.FighterQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

### 3. 技能效果允许触发断言 (`WillTriggerEffectsQuery`)

检查目标实体是否当前允许触发技能效果（未处于沉迷、无效或特殊禁用状态）。

```json
{
  "$type": "PvZCards.Engine.Queries.WillTriggerEffectsQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

### 4. 查找器条件评估 (`QueryEntityCondition`)

针对特定查找器定位到的实体列表评估是否满足条件（`All` 全部满足 / `Any` 任意满足）。

```json
{
  "$type": "PvZCards.Engine.Components.QueryEntityCondition, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "ConditionEvaluationType": "All",
    "Query": {
      "$type": "PvZCards.Engine.Queries.IsAliveQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
      "$data": {}
    }
  }
}
```

#### 参数详解：
- **`ConditionEvaluationType`** (字符串):
  - `"All"`: 要求匹配到的所有实体均满足子 Query 条件。
  - `"Any"`: 要求匹配到的实体中至少有一个满足子 Query 条件。
