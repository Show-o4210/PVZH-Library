# 09. 目标选择器 JSON 复制模板 (Targets)

在 PVZH 的 `EffectEntitiesDescriptor` 技能树中，**目标选择器 (Targets)** 节点用于定义“技能效果（Effects）究竟施加给谁”（例如：施加给自身、全场随从、随机随从、双方英雄或所在线路）。

本篇提供纯净、可直接复制到 JSON 编辑器中（**无内嵌注释，避免语法报错**）的各类目标选择器代码块。

---

## 一、 自身与特定实体选择器

### 1. 目标锁定实体自身 (`SelfTargetDescriptor`)

将技能效果精准作用于拥有该技能的卡牌/随从自身。适用于加自我 Buff、自我无敌等。

```json
{
  "$type": "PvZCards.Engine.Components.SelfTargetDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

## 二、 随从/战斗者选择器

### 1. 目标锁定全场所有随从 (`AllFightersTargetDescriptor`)

选择全场（包含植物阵营与僵尸阵营）的所有存活随从。

```json
{
  "$type": "PvZCards.Engine.Components.AllFightersTargetDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

### 2. 随机选择一个随从 (`RandomFighterTargetDescriptor`)

在符合筛选条件（如符合阵营/职业）的随从集合中，随机选取一个随从作为目标。

```json
{
  "$type": "PvZCards.Engine.Components.RandomFighterTargetDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

### 1. 目标锁定己方英雄 (`HeroTargetDescriptor`)

