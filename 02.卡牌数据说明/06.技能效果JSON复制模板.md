# 06. 技能效果 JSON 复制模板 (Effects)

在 PVZH 的 `EffectEntitiesDescriptor` 技能树中，**技能效果 (Effects)** 节点用于定义“当触发条件与过滤器通过后，游戏引擎具体要执行什么动作”。

本篇提供纯净、可直接复制到 JSON 编辑器中（**无内嵌注释，避免语法报错**）的各类技能效果代码块，并在正文段落中给出详细的参数解说。

---

## 一、 属性增益与修改类

### 1. 基础攻防 Buff 增益 (`BuffEffectDescriptor`)

用于对目标随从增加或减少攻击力与生命值。

```json
{
  "$type": "PvZCards.Engine.Components.BuffEffectDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "AttackAmount": 2,
    "HealthAmount": 2,
    "BuffDuration": "Permanent"
  }
}
```

#### 参数详解：
- **`AttackAmount`** (整数): 攻击力变化量。正数（如 `2`）表示增加攻击力；负数（如 `-1`）表示降低攻击力。
- **`HealthAmount`** (整数): 生命值变化量。正数（如 `2`）表示增加生命值；负数（如 `-2`）表示降低生命值。
- **`BuffDuration`** (字符串): Buff 持续时间。
  - `"Permanent"`: 永久生效。
  - `"ThisTurn"`: 仅本回合生效，回合结束时自动撤销。

---

### 2. 攻击力按倍数翻倍/减半 (`TargetAttackMultiplier`)

根据目标当前的攻击力按倍数进行乘算或除算。

```json
{
  "$type": "PvZCards.Engine.Components.TargetAttackMultiplier, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "Divider": 2
  }
}
```

#### 参数详解：
- **`Divider`** (数值): 攻击力乘算系数。填 `2` 表示攻击力翻倍（即 $\times 2$）；填 `0.5` 表示攻击力减半。

---

### 3. 生命值按倍数翻倍/减半 (`TargetHealthMultiplier`)

```json
{
  "$type": "PvZCards.Engine.Components.TargetHealthMultiplier, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "Divider": 2
  }
}
```

#### 参数详解：
- **`Divider`** (数值): 生命值乘算系数。填 `2` 表示生命值翻倍。

## 二、 特质与能力赋予类 (`GrantAbilityEffectDescriptor`)

用于为随从动态赋予狂热、致命、穿透、装甲等关键字特质。

```json
{
  "$type": "PvZCards.Engine.Components.GrantAbilityEffectDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "GrantableAbilityType": "Frenzy",
    "Duration": "Permanent",
    "AbilityValue": 0
  }
}
```

#### 参数详解：
- **`GrantableAbilityType`** (字符串): 赋予的特质关键字，可选值包括：
  - `"Frenzy"`: 狂热（消灭随从后可再次攻击）
  - `"Deadly"`: 致命（对随从造成伤害时直接秒杀）
  - `"Strikethrough"`: 穿透（同时攻击该路线上的随从与英雄）
  - `"Teamup"`: 组队（同路线可放置两张植物）
  - `"Armor"`: 装甲（受到的伤害减少）
  - `"Overshoot"`: 先攻/先发制人（战斗开始前对英雄造成伤害）
  - `"Unhurtable"`: 无敌（本回合不受任何伤害）
  - `"Untrickable"`: 锦囊免疫（无法成为对方锦囊选中的目标）
  - `"Truestrike"`: 必中/无视护盾（攻击不充能对方英雄的格挡护盾）
- **`Duration`** (字符串): `"Permanent"` (永久) 或 `"ThisTurn"` (仅本回合)。
- **`AbilityValue`** (整数): 特殊参数值：
  - 当赋予 `"Armor"` 时：填减伤数值（如 `1` 代表装甲 1，`2` 代表装甲 2）。
  - 当赋予 `"Overshoot"` 时：填先攻伤害值（如 `2` 代表先发制人 2）。
  - 当赋予 `"Untrickable"` 时：`1` 代表免疫植物锦囊，`2` 代表免疫僵尸锦囊。
  - 其余特质填 `0`。

## 三、 伤害、消灭、弹回与控制类

### 1. 对目标造成指定伤害 (`DamageEffectDescriptor`)

```json

  "$type": "PvZCards.Engine.Components.DamageEffectDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "DamageAmount": 3
  }

```

#### 参数详解：
- **`DamageAmount`** (整数): 造成直接伤害的数值（如 `3` 表示造成 3 点伤害）。

---

#### 参数详解：

## 四、 抽卡、费用与召唤类

### 1. 抽指定张数卡牌 (`DrawCardEffectDescriptor`)

```json
{
  "$type": "PvZCards.Engine.Components.DrawCardEffectDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "NumCards": 1
  }
}
```

#### 参数详解：
- **`NumCards`** (整数): 抽牌张数（如 `1` 表示抽取 1 张卡牌，`2` 表示抽 2 张）。

---

### 2. 修改卡牌出牌费用 (`ChangeCostEffectDescriptor`)

修改手牌或特定卡牌的出牌消耗。

```json
{
  "$type": "PvZCards.Engine.Components.ChangeCostEffectDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "CostDelta": -1,
    "Duration": "Permanent"
  }
}
```

#### 参数详解：
- **`CostDelta`** (整数): 费用增减变化量。负数（如 `-1`）表示减 1 费；正数（如 `2`）表示加 2 费。
- **`Duration`** (字符串): `"Permanent"` (永久减费) 或 `"ThisTurn"` (仅本回合生效)。

---

### 3. 召唤生成新随从实体 (`SpawnEntityEffectDescriptor`)

在指定位置或本线路生成一张新的卡牌实体。

```json
{
  "$type": "PvZCards.Engine.Components.SpawnEntityEffectDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "CardGuid": 900000001
  }
}
```

#### 参数详解：
- **`CardGuid`** (长整数): 目标召唤物的卡牌 GUID 编号。
