# 08. 触发条件与时机 JSON 复制模板 (Triggers)

在 PVZH 的 `EffectEntitiesDescriptor` 技能树中，**触发条件与时机 (Triggers)** 节点用于告知游戏引擎“在对局的哪一个事件发生节点（例如打出卡牌、受到伤害、回合开始、随从死亡等）激活该技能”。

本篇提供纯净、可直接复制到 JSON 编辑器中（**无内嵌注释，避免语法报错**）的各类触发器代码块。

---

## 一、 登场与打出时机

### 1. 当打出此卡牌时 (登场/战吼触发 `OnPlayTriggerDescriptor`)

在玩家或 AI 将卡牌从手牌打出置入战场的瞬间激活。适用于绝大部分战吼技能（例如：“当打出此卡牌时，抽一张牌”）。

```json
{
  "$type": "PvZCards.Engine.Components.OnPlayTriggerDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

## 二、 回合阶段时机

### 1. 当回合开始时触发 (`TurnStartTrigger`)

在每一个回合的初始准备阶段（抓牌/获得阳光或脑子时）自动触发。适用于回合开始加 Buff、回合开始召唤等持续性技能。

```json
{
  "$type": "PvZCards.Engine.Components.TurnStartTrigger, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

### 2. 当回合结束时触发 (`TurnEndTrigger`)

在每一个回合的末尾结束阶段自动触发。

```json
{
  "$type": "PvZCards.Engine.Components.TurnEndTrigger, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

## 三、 战斗与受伤害时机

### 1. 当受到伤害时触发 (`OnHurtTriggerDescriptor`)

当随从或目标实体受到敌方攻击、法术伤害或效果伤害时激活。

```json
{
  "$type": "PvZCards.Engine.Components.OnHurtTriggerDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

### 2. 当本线路战斗交锋结束时 (`LaneCombatEndTrigger`)

当所在线路上的随从攻击/战斗结算完毕后激活。

```json
{
  "$type": "PvZCards.Engine.Components.LaneCombatEndTrigger, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

## 四、 死亡与消灭时机

### 1. 当随从死亡/被消灭时触发 (亡语 `OnDeathTriggerDescriptor`)

当随从生命值归零或被直接秒杀摧毁，离开战场瞬间激活。

```json
{
  "$type": "PvZCards.Engine.Components.OnDeathTriggerDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```

---

## 五、 卡牌流动与抽牌时机

### 1. 当玩家抽取卡牌时触发 (`OnDrawCardTrigger`)

无论是在回合开始抽牌，还是通过技能效果抽牌，只要发生抽卡动作即激活。

```json
{
  "$type": "PvZCards.Engine.Components.OnDrawCardTriggerDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {}
}
```
