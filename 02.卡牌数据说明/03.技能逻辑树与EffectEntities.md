# 03. 技能逻辑树与 EffectEntities

在 PVZH 中，大部分具有动态逻辑的卡牌（例如：“当打出此卡牌时，抽一张牌”、“当受到伤害时，获得+2攻击力”、“亡语：对其余路线造成2点伤害”）都是通过 `EffectEntitiesDescriptor` 节点树来定义的。

---

## 一、 技能树的核心流转架构

技能逻辑树在底层 JSON 中是以一个名为 `EffectEntitiesDescriptor` 的组件形式挂载在 `entity.components` 数组中的。它的执行流转遵循严格的事件驱动链路：

```mermaid
graph LR
    A["Trigger<br/>(触发器: 何时触发)"] --> B["Filter / Query<br/>(过滤器: 条件检查)"]
    B --> C["Target<br/>(目标选择: 对谁生效)"]
    C --> D["Effect<br/>(效果节点: 执行什么动作)"]
```

一个完整的 `EffectEntitiesDescriptor` 组件结构示例如下：

```json
{
  "$type": "PvZCards.Engine.Components.EffectEntitiesDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "entities": [
      {
        "components": [
          {
            "$type": "PvZCards.Engine.Components.EffectEntityGrouping, EngineLib...",
            "$data": { "AbilityGroupId": 0 }
          },
          {
            "$type": "PvZCards.Engine.Components.PlayTrigger, EngineLib...",
            "$data": {}
          },
          {
            "$type": "PvZCards.Engine.Components.DrawCardEffectDescriptor, EngineLib...",
            "$data": { "DrawAmount": 1 }
          }
        ]
      }
    ]
  }
}
```

---

## 二、 常用 Trigger（触发器）节点

触发器用于监听游戏中的事件。当特定事件发生时，技能树被激活并向下传导。

| 触发器节点名称 (`$type` 短名) | 逻辑说明 | 常用场景 |
| :--- | :--- | :--- |
| **PlayTrigger** | 当玩家打出此卡牌时激活（战吼/登场）。 | 法术效果、随从战吼效果。 |
| **EnterBoardTrigger** | 当实体进入战场时激活。 | 包括打出、召唤、搬运等所有进入战场的途径。 |
| **DestroyCardTrigger** | 当卡牌/随从被销毁时激活（亡语）。 | 随从死亡离场效果。 |
| **DamageTrigger** | 当受触发对象受到伤害时激活。 | 受到伤害+攻、受伤抽卡等。 |
| **BuffTrigger** | 当对象获得属性提升（Buff）时激活。 | 获得属性增加时联动。 |
| **DrawCardTrigger** | 当玩家抽取卡牌时激活。 | 抽卡触发加成。 |
| **CombatEndTrigger** | 当战斗阶段结束时激活。 | 回合结束/战斗结束结算。 |
| **ExtraAttackTrigger** | 当单位发起额外攻击时激活。 | 联击/额外攻击触发效果。 |

---

## 三、 常用 Filter & Query（条件过滤器）节点

过滤器用于校验触发事件的对象、位置或状态是否符合技能要求。

### 1. `HasComponentQuery` (组件匹配过滤)

判断目标是否具备特定的 C# 组件类型（如阵营、英雄、环境、低地/高地地形等）：

```json
{
  "$type": "PvZCards.Engine.Queries.HasComponentQuery, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "ComponentType": "PvZCards.Engine.Components.ZombiesComponent, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null"
  }
}
```

### 2. 其他常用 Query 节点

- **IsSelfQuery**: 仅对引发事件的自身卡牌生效。
- **SubtypeQuery**: 检查目标卡牌是否拥有指定的族群类别（如 `Pea`、`Zombie`）。
- **LaneFilterQuery**: 校验目标所在的路线/水道/高地位置。

---

## 四、 常用 Target（目标选择器）节点

目标选择器决定效果（Effect）施加到哪些实体上。

| 目标选择器节点 | 说明与常用场景 |
| :--- | :--- |
| **SelfTarget** | 效果仅作用于本卡牌自身。 |
| **OwnerTarget** | 效果作用于本卡牌的所有者（即我方英雄）。 |
| **OpponentTarget** | 效果作用于敌方英雄。 |
| **AllFightersTarget** | 作用于场上的所有随从（植物和僵尸）。 |
| **LaneTarget** | 作用于本路线或邻近路线上的单位。 |

---

## 五、 常用 Effect（效果执行）节点

效果节点是技能树的终点，负责具体修改游戏状态（如增减攻防、造成伤害、抽卡、销毁等）。

### 1. `DamageEffectDescriptor` (造成伤害)

```json
{
  "$type": "PvZCards.Engine.Components.DamageEffectDescriptor, EngineLib...",
  "$data": {
    "DamageValue": 2
  }
}
```

### 2. `ModifyStatsEffectDescriptor` (修改属性)

```json
{
  "$type": "PvZCards.Engine.Components.ModifyStatsEffectDescriptor, EngineLib...",
  "$data": {
    "AttackValue": 1,
    "HealthValue": 1
  }
}
```

### 3. `DrawCardEffectDescriptor` (抽取卡牌)

```json
{
  "$type": "PvZCards.Engine.Components.DrawCardEffectDescriptor, EngineLib...",
  "$data": {
    "DrawAmount": 1
  }
}
```

### 4. `DestroyCardEffectDescriptor` / `BounceEffect`

- `DestroyCardEffectDescriptor`: 直接销毁指定目标。
- `ReturnToHandFromPlayEffectDescriptor`: 将场上单位弹回手牌（回手/Bounce）。

---

## 六、 赋予型触发能力 (GrantedTriggeredAbility)

对于“双重攻击 (Double Strike)”和“先发制人 (Overshoot)”这类关键字，在底层 JSON 中并非简单的独立组件，而是通过挂载 `GrantedTriggeredAbilityDescriptor` 引用内置规则 GUID 实现的：

| 能力关键字 | GUID 编码 | 底层描述符类型 |
| :--- | :---: | :--- |
| **DoubleStrike** (双重攻击 / Repeater) | `562` | `GrantedTriggeredAbilityDescriptor` |
| **Overshoot** (先发制人) | `564` | `GrantedTriggeredAbilityDescriptor` |

### 赋予双重攻击的组件片段示例

```json
{
  "$type": "PvZCards.Engine.Components.GrantedTriggeredAbilityDescriptor, EngineLib, Version=1.0.0.0, Culture=neutral, PublicKeyToken=null",
  "$data": {
    "AbilityGuid": 562
  }
}
```

---

> [!TIP]
> 当你在编辑复杂卡牌时，如果不确定某个技能节点的 JSON 字段名称，可以在 [PVZH-Card-Editor](https://github.com/Show-o4210/PVZH-Card-Editor) 的**技能逻辑可视化编辑器**中组装节点树，保存为 `.phantom` 项目后，再查看导出生成的 JSON 文件。
