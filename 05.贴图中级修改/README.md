# 05. 贴图中级修改

在基础贴图修改中，我们仅替换了既有 `Texture2D` 的像素内容。但在高级 Mod 开发中，经常需要保留原图并切换重定向引用指针，或者为普通卡牌随从**追加全新的、独立的、可随动画挂载的贴图部件**。

本章节基于 Unity 底层序列化指针与节点树结构，系统讲解 PVZH 贴图进阶修改的技术原理与实战。

## 核心概念速览

1. **A 包与 B 包解耦**：
   - **A 包（素材包）**：存放 `Texture2D` 与 `Sprite` 图片资源。
   - **B 包（结构包）**：存放 `GameObject`、`Transform`、`SpriteRenderer` 等骨骼节点与渲染结构。
2. **指针重定向（资源替换）**：
   无需覆盖原图，直接修改 `SpriteRenderer` 的 `m_Sprite` 指针（`m_FileID` 与 `m_PathID`），让原节点指向新导出的 `Sprite`。
3. **节点插入（新增独立部件）**：
   通过手动构建三位一体新组件并双向绑定到父节点的 `m_Children` 列表中，实现为随从卡牌挂载全新装饰件（如给僵尸帽子上加小饰品、给植物挂新部件等）。
