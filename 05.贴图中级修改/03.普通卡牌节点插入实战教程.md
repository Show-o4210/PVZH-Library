# 03. 普通卡牌节点插入实战教程

英雄角色（Hero）由于包含极复杂的技能动作、多形态与数百个部件组件，对于普通 Modder 门槛过高。而**普通卡牌随从**（如工作区中的 [1f826228d36c6f0478c72b56f17541d2_1](../1f826228d36c6f0478c72b56f17541d2_1) 康加僵尸）结构十分精简，非常适合作为节点插入的实战练习。

本篇以给**康加僵尸头部挂载一个新装饰件（如小帽子 `hat`）**为例，演示完整的精简节点插入流程。

---

## 实战七步法

### 步骤一：导入新图片与创建 Sprite

1. 打开 [1f826228d36c6f0478c72b56f17541d2_1](../1f826228d36c6f0478c72b56f17541d2_1) 包。
2. 导入帽子图片 `hat.png` 生成 `Texture2D`。
3. 右键点击创建对应的 `Sprite`，在列表视窗记录其 **PathID**（假设为 **`80001`**）。

---

### 步骤二：复制组件模板与分配新 PathID

找一组原版已经正常工作的节点（例如原本手掌部件 `conga_palm` 的组件）：
1. 分别导出它的 `GameObject`、`Transform` 与 `SpriteRenderer` 的 Dump 文本。
2. 为这 3 个新组件分配在当前 Bundle 中未被占用的全新 PathID：
   - **`90001`** -> 新 GameObject
   - **`90002`** -> 新 Transform
   - **`90003`** -> 新 SpriteRenderer

---

### 步骤三：修改对象名称 (m_Name)

打开 `90001` (GameObject Dump) 文本：
```yaml
0 string m_Name = "hat"
```
将名称改为 `"hat"`。

---

### 步骤四：建立三位一体内部闭环

1. **GameObject (`90001`)**：将 `m_Component` 数组 `size` 设为 `2`，分别指向新 Transform 和新 SpriteRenderer：
   ```yaml
   m_Component:
     size: 2
     data:
     - {fileID: 0, pathID: 90002}
     - {fileID: 0, pathID: 90003}
   ```
2. **Transform (`90002`)**：将 `m_GameObject` 指向新 GameObject：
   ```yaml
   m_GameObject: {fileID: 0, pathID: 90001}
   ```
3. **SpriteRenderer (`90003`)**：将 `m_GameObject` 指向新 GameObject：
   ```yaml
   m_GameObject: {fileID: 0, pathID: 90001}
   ```

---

### 步骤五：配置贴图资源引用

打开 `90003` (SpriteRenderer Dump) 文本，找到 `m_Sprite` 字段，将其指向步骤一创建的新 Sprite (`80001`)：

```yaml
m_Sprite: {fileID: 0, pathID: 80001}
```

---

### 步骤六：绑定父子层级关系 (挂载到头部节点)

假设康加僵尸原版头部节点 `conga_head` 的 Transform PathID 为 **`1020`**：

1. **子节点指向父节点**：
   打开新 Transform (`90002`) Dump 文本，找到 `m_Father` 字段：
   ```yaml
   m_Father: {fileID: 0, pathID: 1020}
   ```
2. **父节点注册子节点**：
   导出头部 Transform (`1020`) 的 Dump 文本，找到 `m_Children` 数组，将 `size` 增加 `1`，并在末尾添加子节点：
   ```yaml
   m_Children:
     size: 5  # 原为 4，增加到 5
     data:
     - ...
     - {fileID: 0, pathID: 90002}
   ```

---

### 步骤七：导入 Dump 并保存

1. 在 UABEA 中分别对修改后的四个节点（GameObject `90001`、Transform `90002`、SpriteRenderer `90003`、父 Transform `1020`）执行 **`Import Dump`**。
2. 在 `Info` 视窗点击 `File` -> `Save`。
3. 返回主界面点击 `File` -> `Save` 导出新 Bundle 文件。

替换到手机后，新的帽子部件就会完美挂载在康加僵尸的头部，并跟随头部动画一同摆动！
